Fixes #3792.

Gaining or losing its bar (actions, menu or quick reactions) swapped the content box between being a direct child of `[data-ouro-message-body]` and being nested one level deeper inside a new wrapper `<div>`. Because both elements are a plain `div` at that position, React kept the host node but gave it brand-new children, so the content box underneath (text, picture, quote) remounted instead of staying put.

[The fix always renders the same wrapper around the content box, whether or not the message has a bar, so the content box's depth never changes and React keeps it across the transition](registry/ouro/components/ouro/message/message.test.tsx "verify:testExists(registry/ouro/components/ouro/message/message.test.tsx::Message content identity > keeps the content box the same element as a message gains or loses its bar (#3792))").
