- The test kit (`ouro-testing`) adds `lib/ouro/testing/announcements.ts`: `watchAnnouncements()` records the text each live region announces (`role="status"`, `role="alert"`, `role="log"` or `aria-live`, portals included, nothing under `aria-hidden`), once per region for each batch of DOM changes: text added to or changed in a region already on the page, and the text an assertive region (`role="alert"`, `aria-live="assertive"`) is added with, but not a new polite region's first text, nor text under `aria-live="off"` or beside a region in an added subtree. It has `changes`, `matching(text)`, `count(text)` and `stop()`, so a test proves a message is heard once per change and in which region; Toast's tests use it (see "Proving announcements" in docs/guides/testing.md).
