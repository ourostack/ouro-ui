- The test kit (`ouro-testing`) adds `lib/ouro/testing/announcements.ts`: `watchAnnouncements()` records the text each live region announces (`role="status"`, `role="alert"`, `role="log"` or `aria-live`, portals included, nothing under `aria-hidden`), with `changes`, `matching(text)`, `count(text)` and `stop()`, so a test proves a message is heard once per change and in which region; Toast's tests use it (see "Proving announcements" in docs/guides/testing.md).
