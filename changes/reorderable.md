- New: `Reorderable`, a list from `items` (`{ id, label, content }`) that the user puts in order with each row's drag handle, a 44px target on a touch screen, or from the keyboard: Space picks a row up, the arrow keys move it, Space drops it and Escape puts it back. Each step is announced with the row's position ("Sear the ribs moved. Position 3 of 7."), and every spoken string is a prop with an English default (`handleLabel`, `instructionsLabel`, `pickedUpLabel`, `movedLabel`, `droppedLabel`, `canceledLabel`). Holding a dragged row near the top or bottom edge scrolls the list or the page, a touch that starts outside a handle scrolls as usual, and `onReorder(ids, { id, from, to })` reports each drop once. A dragged row follows the pointer from where it took hold, resists past either end of the list, and springs into its place on the drop, as do the rows it passed; a flick drops it the way it was moving, and a row can be picked up again before it has come to rest. With reduced motion the rows are in place at once.
