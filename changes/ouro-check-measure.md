- Changed: Ouro check's `long-lines` rule is opt-in. It runs only where `ouro-check.json` declares a measure, such as `{ "measure": { "**": "100 chars" } }` or `{ "measure": { "main .chat-message": "800px" } }`, because a fixed text measure is a design choice, not a default. A measure is `px`, `ch` or `chars` (characters a rendered line holds), and `"**"` with `"100 chars"` checks what the rule checked before. Opt-out reasons are read trimmed, and the page's attributes are no longer rewritten ([guide](https://ui.ouro.bot/docs/guardrails/#long-lines-are-opt-in), [test](https://github.com/ourostack/ouro-ui/blob/main/scripts/check/check.test.mts "verify:testExists(scripts/check/check.test.mts::Ouro check > checks long lines only against a measure the project declares: none without one, a page glob's prose, or a selector's elements)")).
