- New: Ouro AX, for the interfaces agents use (CLIs, HTTP APIs, MCP servers): `ouro-ax` and its `ax-*` items, [copy-in TypeScript for Node with no dependencies](scripts/registry.test.mjs "verify:testExists(scripts/registry.test.mjs::Ouro AX items depend on the ax items they import)"). One command definition gives the parser, help, `help --json`, `--json`, exit codes, one-line errors that name the fix and an MCP tool; an action returns a typed outcome, a wait returns a typed wait with a cursor, and work events say who acted for whom. `ax-claims` is the standard as checkable claims, and `ax-xray` checks a CLI, an HTTP API or an MCP server against them from outside, against an inventory the interface generates, calling what other people see only on a proven mock. Guide: docs/guides/ax.md.
