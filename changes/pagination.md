- New: `Pagination`, with Previous, page numbers with gaps and Next, and the current page marked `aria-current="page"`. With `href` (a string with `{page}`, which a Server Component can pass, or a function) every page is a plain link that works with no JavaScript; with `onPageChange` the pages are buttons. Below 640px the numbers give way to "Page 3 of 12". Without `pageCount`, for a list with no count of its rows, it shows Previous and Next only, and `hasNextPage` enables Next. Every label is a prop: `label`, `previousLabel`, `nextLabel`, `pageLabel`, `summaryLabel`.
