- New: `Form`, a `<form>` that validates with the browser's own constraints and takes `errors` by field name (`errors={actionData?.errors}`). Each message shows on the field with that `name`, linked through `aria-describedby` in the server HTML too, and after a submit focus moves to the first invalid field. `action` and `method` pass through, and `render={<RouterForm />}` submits through React Router.
- New: `EditSheet`, a `Dialog` with a `Form` inside (a bottom sheet on phones): `onSubmit` gets the fields as `FormData` and may return errors or a promise; the save button shows `loading` while it runs, errors land on their fields, and success closes it and returns focus to the trigger.
- `Field` (and every control built on it) shows a `Form`'s error for its `name` when it has no `error` of its own, and drops it once the user changes the control. The label now has an id of its own (`<id>-label`).
