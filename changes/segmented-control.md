- New: `SegmentedControl`, an iOS-style control on Base UI's ToggleGroup in single mode for switching a view in place: equal segments with a raised thumb that slides to the checked one, `label` with `hideLabel`, `items`, `fullWidth`, and exactly one segment checked. Screen readers hear a radio group, the arrow keys check the next segment as they do for radio buttons, and `name` submits the value with a form.
