- Changed: `OuroProvider` loads the squircle polyfill by default, so engines without native `corner-shape` (a WebKit web view) draw true squircles on its rounded surfaces with nothing for an app to remember; pass `squircles={false}` to keep round corners, and give an element of your own `data-corner-shape="squircle"` to draw it too. The engine no longer re-measures descendants when an element's style changes without touching a custom property.
