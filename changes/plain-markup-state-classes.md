- ouro-plain: a new item for markup that is not an Ouro component. Add it once, after `ouro-base`, if your app builds rows and controls as strings or prerenders them to read without a script. The classes for that markup (`ouro-focus-ring`, `ouro-row`, `ouro-disclosure`, `ouro-skip-link`, `ouro-reveal` and the rest) moved from `ouro-base` into it, so an app built only from components no longer carries their CSS; the plain stylesheet `site/public/css/ouro-plain.css` has them for a page without Tailwind.
- ouro-plain: `ouro-nav-link` (links in a nav, the current one marked), `ouro-toggle` (a pressed button), `ouro-segmented` with `ouro-segment` (labels around radios or checkboxes drawn as SegmentedControl) and `ouro-option` (a selected option) give plain markup the states of Link, Toggle, SegmentedControl and Command, and the Ouro source rule counts them as Ouro's.
