# Incumbent fixture

A small Vite and React app on Mantine, with its own `--acme-*` tokens instead of shadcn's. Its Settings page is
still Mantine; its Billing page is the one moved to Ouro HX. It is what Ouro's checks are run against
to find what stops Ouro working beside another design system. `scripts/incumbent-fixture.test.mjs`
runs the source rule over it.
