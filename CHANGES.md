# Changes in this release

- New: Ouro Current's update pull request lists the Ouro check rules new to an app since its last release, from `registry/ouro/check/new-rules.json`, with the day a rule gates from, so an app hears of a rule before it fails its check.
- Changed: the page patterns' JSDoc now lists what a pattern already does, what the app wires up and the props of the parts it uses, and the patterns guide says to test only what an app adds.
