# Changes in this release

- Changed: the A2UI module, the agent door's generator and the token claim sets come from [core v0.21.0](https://github.com/ourostack/ouro-ui-core/releases/tag/v0.21.0 "verify:urlOk(https://github.com/ourostack/ouro-ui-core/releases/tag/v0.21.0)"), which follows the tokens of this release.
- New: `ComposedSurface`, `A2UISurface` and `OuroMcpApp` take `components`, a map from your catalog's own component names to functions that draw them; a name without a renderer is left out and development builds say which.
- Changed: web vendors [core v0.21.0](https://github.com/ourostack/ouro-ui-core/releases/tag/v0.21.0 "verify:urlOk(https://github.com/ourostack/ouro-ui-core/releases/tag/v0.21.0)"), whose `applyTreeUpdate` changes a composed tree by node id and its data by JSON pointer ([the decision record](https://github.com/ourostack/ouro-ui-core/blob/c90da442be466dfd0f80b435c3a44d3c175c6092/docs/decisions/2026-11-18-composed-tree-updates.md "verify:urlOk(https://github.com/ourostack/ouro-ui-core/blob/c90da442be466dfd0f80b435c3a44d3c175c6092/docs/decisions/2026-11-18-composed-tree-updates.md)")). `OuroMcpApp` applies a tool result whose `structuredContent.ouro` carries `update` to the tree it shows; an update that can't apply shows the same short alert as a tree that fails the checks, and the agent hears why.
- New: `Progress` takes `size="thin"`, a hairline bar for under a list header; it keeps its name and value.
