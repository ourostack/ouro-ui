# Changes in this release

- Fix: `audit()` leaves the page as it found it: its Tab walk puts focus back where it was, with a focus ring only if it had one, and nothing focused if nothing was, with the selection or a field's caret as it was ([test](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/testing/axe.test.ts "verify:testExists(registry/ouro/lib/ouro/testing/axe.test.ts::audit > puts back a field's caret and selected text, which Tab into a field selects whole, and the page's selection)")), and every scroll position it moved to measure text goes back ([test](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/testing/axe.test.ts "verify:testExists(registry/ouro/lib/ouro/testing/axe.test.ts::audit > leaves focus where its Tab walk found it: nothing focused stays so, and a focus ring shows after only if it showed before)"), [test](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/testing/axe.test.ts "verify:testExists(registry/ouro/lib/ouro/testing/axe.test.ts::audit > puts back every scroll position it moves to measure text, the page's and a scrolled box's)")). Before, with nothing focused, the walk left focus on the last control it reached, which could fan out and pause a toast stack.
- Fix: `audit()` and `measureTextContrast()` no longer leave an empty `style` attribute on the focused field when they screenshot the page ([test](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/testing/axe.test.ts "verify:testExists(registry/ouro/lib/ouro/testing/axe.test.ts::audit > leaves no trace on the focused field when it screenshots the page)")).
- Change: `audit()` throws, naming the change, when its Tab walk changes what is open on the page and it has not changed back a second later, such as closing a popup that closes when focus leaves it ([test](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/testing/axe.test.ts "verify:testExists(registry/ouro/lib/ouro/testing/axe.test.ts::audit > fails, naming what changed, when its Tab walk closes a popup that focus leaving closes, which it cannot open again)")). Before, it returned its findings and left the page changed.
- Fix: the census puts back the page's own `window.axe`, or none, when it is done, and its own axe-core stops listening for frame messages ([test](https://github.com/ourostack/ouro-ui/blob/main/scripts/kits/census-page.test.mjs "verify:testExists(scripts/kits/census-page.test.mjs::collectCensus > puts back the page's own window.axe, or none, once it has read the page, even when the controls never settle)")).
- Fix: a collapsed stack of toasts no longer hides anything from screen readers, so a touch screen reader such as VoiceOver on iPhone reaches every toast, a destructive one included, with its action and dismiss buttons ([test](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/components/ouro/toast/toaster.test.tsx "verify:testExists(registry/ouro/components/ouro/toast/toaster.test.tsx::toast() > keeps every toast, its action and its dismiss button reachable by a screen reader while the stack rests collapsed)"), [spec](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/e2e/ouro/toaster.spec.ts "verify:testExists(registry/ouro/e2e/ouro/toaster.spec.ts::a screen reader finds every toast and its buttons in the collapsed stack, before anything is focused or hovered)")). Before, Base UI hid the dismiss buttons until the stack was hovered or focused from the keyboard, and hid a destructive toast whole until it had focus.
- Change: the Notifications region is no longer a live region; two live regions last inside it say the words of each toast's message and description, politely or, for a destructive toast, assertively from a `role="alert"`, and never its buttons; the words leave them seven seconds later ([test](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/components/ouro/toast/toaster.test.tsx "verify:testExists(registry/ouro/components/ouro/toast/toaster.test.tsx::toast() > is announced once, its message and description only: politely, and a destructive toast assertively (Review Focus 5))")). For those seconds, its words are in the page twice, so find a toast in a test by its role and name, `getByRole("dialog", { name: "Saved" })` (`"alertdialog"` for a destructive one), not by its text.
- Fix: focus in a toast fans the stack out and pauses it however it came, as a screen reader moves it, where Base UI did so only for focus from the keyboard ([test](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/components/ouro/toast/toaster.test.tsx "verify:testExists(registry/ouro/components/ouro/toast/toaster.test.tsx::toast() > fans the stack out and waits while focus is in a toast though no key moved it there, as a screen reader moves it, and folds it when focus leaves)")).
