# Changes in this release

- New: Combobox [`empty`, content for the empty state in place of `emptyLabel` (such as a picture with words), said politely once each time nothing comes to match](registry/ouro/components/ouro/combobox/combobox.test.tsx "verify:testExists(registry/ouro/components/ouro/combobox/combobox.test.tsx::Combobox > takes content for its empty state, such as a picture with words, said politely once each time nothing matches)"), in the popup and the phone's sheet, as Command's `empty` is.
- Fixed: Command's search input [prompts with its `searchLabel` when no `placeholder` is given](registry/ouro/components/ouro/command/command.test.tsx "verify:testExists(registry/ouro/components/ouro/command/command.test.tsx::Command > prompts with its search label when no placeholder is given, so what the field says and what it is named agree)"), so what the field shows matches what a screen reader hears.
- Changed: Ouro Feel [counts `blankFramesInset` as a chat app's frame meter does](scripts/feel.test.mjs "verify:testExists(scripts/feel.test.mjs::Ouro Feel's probe counts a blank frame as a chat app's frame meter does: no row with height in the view less 40 px at its top and bottom, or a placeholder anywhere in view, rows or none)"): no row with height in the view less 40 px at its top and bottom, or a placeholder anywhere in view, in any frame, rows or none.
- Changed: Ouro Feel [times input to motion and counts dead input as the frame meter does](scripts/feel.test.mjs "verify:testExists(scripts/feel.test.mjs::Ouro Feel's probe times each wheel event to the first frame that moved the list its way, and counts those it never moved)"): a wheel at the end it turns toward counts as neither (`inputAtEdge`), the list's move is read frame to frame from the first frame that began after the wheel, whatever order the page saw them in, and a wheel that never moved it counts until the last frame.
- Changed: Ouro Feel [lets the reader's row go on a frame with no list on the page](scripts/feel.test.mjs "verify:testExists(scripts/feel.test.mjs::Ouro Feel's probe judges no jump on the frame a list comes back to the page, after a wheel turned while it was gone)"), a list given as an element and taken off the page included, so a list that comes back is followed from its first frame and a wheel while it was gone counts as at its end (`inputAtEdge`).
- New: Ouro check's first-run harness plays a managed Mac's SSO extension (scripts/ouro/check/first-run-sso.ts): [its stand-in holds the identity provider's silent sign-in unanswered, as the extension does with no web view in a window](scripts/check/first-run-sso.test.mts "verify:testExists(scripts/check/first-run-sso.test.mts::first-run harness: a managed Mac's SSO extension > the stand-in holds the silent sign-in unanswered, passes the sign-in page, and leaves a client with no ALPN alone)"), and the `managedMac` detour fails an app that never offers a way in while it waits.
