# Changes in this release

- New: A2UISurface shows the UI an agent composed in A2UI with Ouro HX. Its buttons are your declared actions, and pressing one follows its consent class.
- Avatars: a person is a squircle, a team a squircle with a second edge behind it, and an AI agent a less-rounded white tile with a presence dot, replacing the hexagon (`shape="agent"` is new, `shape="hexagon"` is gone).
- New: Ouro AX's flags can [repeat](registry/ouro/ax/command.test.mts "verify:testExists(registry/ouro/ax/command.test.mts::a repeat flag collects each value in order, in either form, and is absent when not given)"), so `--ready a --ready b` gives a list. A tool can define [a default command beside its named commands](registry/ouro/ax/command.test.mts "verify:testExists(registry/ouro/ax/command.test.mts::defineCli needs command or commands, and takes both: the default beside the named commands)"), which [runs when no command word leads](registry/ouro/ax/command.test.mts "verify:testExists(registry/ouro/ax/command.test.mts::a tool with a default command runs it for any leading word that is not a command word, and a command word goes after --)").
- New: `ax-surfaces` checks a repository's agent-facing words from a JSON manifest: an error that does not open with its fix or lacks a stable code, a tool description that does not say when to use the tool or runs past its size budget, an action reply that leaves out its outcome, and a message that sends the agent to run a script; with a baseline file, CI fails on a new finding and on a fixed one still listed.
- Browser tests run in more parallel shards, so a pull request finishes its browser checks sooner.
- Fixed: Ouro check opens its blank page again when a navigation the page started itself wins over it, instead of stopping with "interrupted by another navigation".
- Fix: Ouro check seeks a played video back to its first frame again when WebKit reports where playback stopped after the first seek, so it photographs the first frame.
- Ouro check: `type-scale` [counts font weights within a text role](test/check-design-in-page.test.ts "verify:testExists(test/check-design-in-page.test.ts::findDesignIssues: type-scale and shadow-scale > counts weights within a role: a heading's weight leaves the running text its regular, medium and bold)"), headings apart from the rest of the text, so a page with Hero's semibold title and medium eyebrow can still set bold in its body; running text, or headings, in more than three weights still fails.
- Fixed: the claims check [accepts a cited path with a `$` in it](registry/ouro/lib/ouro/claims.test.ts "verify:testExists(registry/ouro/lib/ouro/claims.test.ts::parseClaimSource > reads a route file whose name holds a $, as Remix and React Router name a route's parameter)"), as Remix and React Router name a route's parameter (`app/routes/recipes.$id.tsx`).
- New: Composer's `hideSendDisabledReason` keeps sending off, with its reason for screen readers and on Enter, without drawing the reason line under the box.
- ConversationList draws only the rows its view and overscan reach, from the first frame, in a long list, so the first frame is the finished screen and nothing is added after it.
- Fixed: a Switch, radio, slider thumb or avatar ring that should stay round turned into a rounded block wherever the squircle polyfill's stylesheet was loaded, and a Button, Toggle or Badge hover wash drew round corners inside a squircle outline.
- New: an app that draws its own bar across the window's top sets `--ouro-inset-top` to its height, and [a centred dialog, its backdrop and a full-screen Lightbox open below it](registry/ouro/components/ouro/dialog/dialog-parts.tsx "verify:testExists(registry/ouro/components/ouro/dialog/dialog.test.tsx::Dialog below an app's own bar > starts the backdrop and the centered viewport below --ouro-inset-top, and centres in the space under it)"); Sheet, and Dialog's sheet on a phone, are unchanged.
- Fixed: the test kit's `commands.emulateMedia` [names the query a frame never matched](registry/ouro/lib/ouro/testing/commands.test.ts "verify:testExists(registry/ouro/lib/ouro/testing/commands.test.ts::emulateMedia names the query the frame never matched, even when its last read does not answer)"), even when the frame's last read stalls on a loaded runner, rather than saying the frame did not answer.
- Changed: `ax-flows run` runs on [Ouro AX](registry/ouro/ax/command.test.mts "verify:testExists(registry/ouro/ax/command.test.mts::a tool with one command reads every token as the command's arguments and flags, with no command word)"), so its `--help` and `--json` come from the kit. A refused option or suite module prints [one line that ends with the fix](registry/ouro/ax/flows.test.mts "verify:testExists(registry/ouro/ax/flows.test.mts::the command's --help is the Ouro AX kit's, and an unknown flag is one line that names the fix, exit 2)"), and under `--json` stdout holds [the outcome alone](registry/ouro/ax/flows.test.mts "verify:testExists(registry/ouro/ax/flows.test.mts::--json prints the outcome alone on stdout, and each flow's line on stderr)").
- New: Hero's `breadcrumb` [sets a trail above the eyebrow, and `badge` a status beside it](registry/ouro/components/ouro/hero/hero.test.tsx "verify:testExists(registry/ouro/components/ouro/hero/hero.test.tsx::Hero > puts the trail above the eyebrow and the badge beside it, on the text's edge)"), on the text's edge, and its `children` [go under the actions, beside the picture in the split layout](registry/ouro/components/ouro/hero/hero.test.tsx "verify:testExists(registry/ouro/components/ouro/hero/hero.test.tsx::Hero > sets more under the actions in the text column, beside the art in the split layout)"), for a byline, a note or a short recording. The names follow PageHeader's `breadcrumb` and `children` and Sidebar's `badge`.
- New: Hero's `fullWidth` [stretches it to the width of its container](registry/ouro/components/ouro/hero/hero.test.tsx "verify:testExists(registry/ouro/components/ouro/hero/hero.test.tsx::Hero > takes its container's width with fullWidth, with no gutter or cap of its own)"), with no gutter or cap of its own, for a hero inside a page column that already sets the width.
- Hero: the lede is [balanced into lines of even length in every layout](registry/ouro/components/ouro/hero/hero.test.tsx "verify:testExists(registry/ouro/components/ouro/hero/hero.test.tsx::Hero > balances the lede in each layout, so its last line is never short)") with `text-wrap: balance`, so its last line is never short; set each phrase in an `inline-block` span to choose where it breaks.
- Hero: the lede [runs the full width of the text column](registry/ouro/components/ouro/hero/hero.test.tsx "verify:testExists(registry/ouro/components/ouro/hero/hero.test.tsx::Hero > runs the lede the full width of the text column in each layout)"), like the title, instead of stopping short of it at a character cap.
- Hero: the media wrapper [carries `data-starting-style` only while a hydrated page sees the rise running](registry/ouro/components/ouro/hero/hero.test.tsx "verify:testExists(registry/ouro/components/ouro/hero/hero.test.tsx::Hero > marks the rise only while it runs, so server HTML that never hydrates carries no marker)"), so server HTML that never hydrates, such as an Astro page without client JavaScript, keeps no leftover marker.
- Hero: `motion="rise"` is now [a transition from `@starting-style` in Hero's own classes, with no keyframes and no stylesheet to import](registry/ouro/components/ouro/hero/hero.test.tsx "verify:testExists(registry/ouro/components/ouro/hero/hero.test.tsx::Hero > rises with no keyframes: its own transition, on ouro-base's durations and easing)"), on `ouro-base`'s durations and easing. `ouro-base` keeps its `ouro-hero-rise` and `ouro-hero-fade` keyframes for copies of Hero from before this change.
- Fixed: Navbar's sheet, built afresh after a close, [asks for its content's idle turn](registry/ouro/components/ouro/navbar/navbar.transition.test.tsx "verify:testExists(registry/ouro/components/ouro/navbar/navbar.transition.test.tsx::asks for the fresh sheet's content turn after a close, even when the last content's transition had not committed)") even when the last open's content had not committed by the time it closed, so the next press still opens a sheet already built.
- Changed: NavigationRail's first commit (a mount, or server HTML hydrating) [no longer lays the page out or renders twice](registry/ouro/components/ouro/navigation-rail/navigation-rail.test.tsx "verify:testExists(registry/ouro/components/ouro/navigation-rail/navigation-rail.test.tsx::NavigationRail fit > lays nothing out and renders once in its first commit, and paints its fit in its first frame)"): its resize observer measures once the page is laid out, before the first paint, so a rail that overflows still paints with its items already under More.
- New: OuroMcpApp is the view an MCP server returns for agent-composed UI (MCP Apps). It shows the tool result's A2UI card with Ouro HX, and a pressed button calls its action's own tool through the host, once the person confirms when the action is consequential. `node scripts/mcp-app.mts build` makes it one HTML file with the app's catalog embedded.
- Fixed: the shipped Stack, Row, Tabs, Empty, Message and SnapPiP tests pass on the Chromium that Playwright 1.65 drives, which writes `flex-start` back as `flow-start` and tabs on from a blurred element; the test kit's new [`computedValue`](registry/ouro/lib/ouro/testing/computed.ts "verify:testExists(registry/ouro/lib/ouro/testing/computed.test.ts::computedValue > gives the value as this browser computes it for the declaration, and leaves no probe behind)") gives a declaration's value as the running browser writes it.
- Changed: Porthole's first commit (a mount, or server HTML hydrating) [no longer lays the page out](registry/ouro/components/ouro/porthole/porthole.test.tsx "verify:testExists(registry/ouro/components/ouro/porthole/porthole.test.tsx::Porthole > lays nothing out and renders once in its first commit, and paints its width in its first frame)"): its resize observer measures the width and the room once the page is laid out, before the first paint, so the first frame still paints the final width.
- Pull requests run the install test and the heavy tier unless the plan proves the change cannot reach them ([ci.yml](.github/workflows/ci.yml "verify:testExists(scripts/workflows.test.mjs::a pull request into main skips the install test or the heavy tier only when the plan proves the change cannot reach it)")).
- The Switch's thumb is a Liquid Glass lens (the `--ouro-glass*` tokens in `ouro-base`), and a solid surface with reduced transparency or more contrast.
- The script tests that drive a browser run in shards split by measured time, which shortens CI.
- New: source rules flag an avatar or presence dot drawn by hand (`hand-drawn-avatar`, `hand-drawn-presence-dot`) and name `Avatar` to use instead.
- New: the source rules find a corner radius fixed by hand in a class, so an app can move it onto the theme's radius scale.
- New: the source rules find a hero drawn by hand as a `section` or `header` with a hero class, so an app can move it to the registry's `Hero`.
- New: the source rules find a switch drawn by hand with `role="switch"`, so an app can move it to the registry's `Switch`.
- Fixed: the squircle polyfill stops re-measuring corners in a loop while idle, which slowed typing.
- Changed: `Text` [wraps with `text-wrap: pretty`, so a paragraph does not end on one stranded word](registry/ouro/components/ouro/text/text.test.tsx "verify:testExists(registry/ouro/components/ouro/text/text.test.tsx::Text > wraps prettily so a paragraph does not end on one word, and drops it with truncate)"). `truncate` and `lines` keep their own wrapping. A `Field` description, including the one under a `Switch` or `Checkbox` label, [wraps the same way](registry/ouro/components/ouro/field/field.test.tsx "verify:testExists(registry/ouro/components/ouro/field/field.test.tsx::Field wiring > wraps the description prettily so it does not end on one word)").
- Changed: an auto-growing TextArea in a browser that supports `field-sizing: content` (Chromium) [grows itself and forces no layout per keystroke](registry/ouro/components/ouro/text-field/text-area.test.tsx "verify:testExists(registry/ouro/components/ouro/text-field/text-area.test.tsx::TextArea autoGrow > forces no layout as the text changes where the browser grows it, and one measure per edit elsewhere)"): `rows` and `maxRows` become `min-height` and `max-height` in `lh` units, and other browsers keep the measured fit.
- New: ThreadRail, a thread beside its conversation: a labelled landmark with a header, a close button and Escape, that takes focus when it opens and gives it back when it closes.
