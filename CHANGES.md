# Changes in this release

- Menu, Toolbar, Composer, Message and Command: `aria-keyshortcuts` names the platform's modifier once the page has [hydrated](registry/ouro/components/ouro/toolbar/toolbar.test.tsx "verify:testExists(registry/ouro/components/ouro/toolbar/toolbar.test.tsx::Toolbar server rendering > renders every control on the server and hydrates with no warning)"), so screen readers read [one shortcut, not Control and Meta both](registry/ouro/components/ouro/menu/menu.test.tsx "verify:testExists(registry/ouro/components/ouro/menu/menu.test.tsx::Menu shortcuts' platform > names mod as %s's own modifier on every kind of item, and no other)").
- Navbar: when the brand and actions do not fit side by side (large text on a phone), the actions move to a second row instead of running off the screen.
