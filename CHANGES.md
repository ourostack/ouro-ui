- Changed: the Apple pages and the Platforms pages [name Apple's 1.8.0](site/src/apple/kit.json "verify:equals(site/src/apple/kit.json#release)=1.8.0"), and the parity table lists [each view a Swift file declares](scripts/parity-matrix.test.mjs "verify:fileLine(scripts/parity-matrix.test.mjs, /counts each, and not its support types/)"), so `OuroSkeleton`, `OuroSpinner` and `OuroProgress` all show.
- New: [Composer takes `format="rich"`](registry/ouro/components/ouro/composer/composer.rich.test.tsx "verify:testExists(registry/ouro/components/ouro/composer/composer.rich.test.tsx::Composer rich mode > shows Markdown marks as formatting, and writes formatting back out as the same Markdown)"), a rich-text box with bold, italic, underline, strikethrough and code that reads and writes light Markdown; its editor is a Lexical chunk loaded on first use, so a page with only plain composers loads none of it, and the registry item adds the `lexical` and `@lexical/*` dependencies.
