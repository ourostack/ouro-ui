# Changes in this release

- Fix: Composer's rich editor opts out of ouro-check's first-paint-swap rule, since it intentionally replaces the server's plain textarea once its editor module loads.
- Fixed: Ouro check's `count-badge` rule [reads a count's numerals finer than the whole pixels Linux rounds a font's metrics to](test/check-design-in-page.test.ts "verify:testExists(test/check-design-in-page.test.ts::findDesignIssues: count-badge > passes centred counts at one offset, either side of their icons, and what is no count badge or is opted out) verify:fileLine(registry/ouro/check/design-check.ts, /and 1px high in Chromium/)"), so on Linux WebKit no longer reads every count as centred and Chromium no longer reads a centred count as 1px high.
- New: [Dialog takes `onOpenChangeComplete`](registry/ouro/components/ouro/dialog/dialog.test.tsx "verify:testExists(registry/ouro/components/ouro/dialog/dialog.test.tsx::onOpenChangeComplete > tells once an open and a close have finished, centered and as a sheet)"), called once an open or a close has finished, so an app that keeps a dialog mounted can unmount it after its exit.
- New: Ouro check's [`doubled-line`, `count-badge` and `pointer-not-control` rules](scripts/check/check.test.mts "verify:testExists(scripts/check/check.test.mts::Ouro check > finds each rule on its fail page and nothing on any pass page, with a report, a contact sheet and close-ups) verify:fileLine(registry/ouro/check/new-rules.json, /\"rule\": \"pointer-not-control\"/)") find a line drawn twice where one separates, a count badge that is clipped, off its middle or at another offset from its icon, and a pointer cursor on something that is not a control; they are in `new-rules.json`, so an app's existing findings are recorded as known when it updates.
- Changed: Ouro UI's own build tooling now parses with [the TypeScript 7.1 API](package.json "verify:fileLine(package.json, /typescript7.: .npm:typescript@7\.1\.0-beta/)"); the shipped `lib-claims` and `ouro-source-rules` items keep their TypeScript floor.
