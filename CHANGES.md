# Changes in this release

- Autocomplete's suggestion list follows its trigger character when a web font finishes loading while the list is open.
- New: pass `media` to `Hero` instead of `picture` to show something live in the picture's place, such as a video or a demo; it rises in the same way, and `mediaWidth` keeps it from being drawn larger than its file. A `description` made of blocks, such as paragraphs or a list, is set in a `<div>` instead of a `<p>`.
- Fixed: the shipped test setup now loads every font face the app's stylesheet declares before a test file's first test, so a web font that finishes loading mid-test [no longer moves text between a test's layout reads](registry/ouro/lib/ouro/testing/setup.ts "verify:testExists(registry/ouro/lib/ouro/testing/fonts.test.ts::loadFonts > loads a declared font face, which the browser otherwise loads only once text uses it)").
- MessageList: a test pins the drift and rest limits at their boundary, so the reader's place after the wheel rests cannot drift unseen.
- Changed: CI shard times are refreshed from the latest merge-queue run, so shards finish closer together.
- Fixed: the skip link in `SidebarLayout` and `StackedLayout` sets its font size and line height in rem whether or not it has focus, so it follows the root font size. While hidden it used to inherit its page's text size, so a page with a px text size shrank it off the scale ([test](registry/ouro/components/ouro/sidebar/sidebar-layout.test.tsx "verify:testExists(registry/ouro/components/ouro/sidebar/sidebar-layout.test.tsx::SidebarLayout > sizes the skip link in rem, so it follows the root font size whether or not it has focus)")).
- Fixed: the testing kit keeps each test's media emulation (reduced motion, forced colours, colour scheme and contrast) to the test that set it: each file starts from the browser's defaults, its `beforeAll` media holds for all its tests, and each test puts back the media it found [before the next test](registry/ouro/lib/ouro/testing/setup.ts "verify:fileLine(registry/ouro/lib/ouro/testing/setup.ts, /commands\.restoreMedia\(mediaBeforeTest\)/)"), so a test that sets reduced motion [no longer leaves it on for the next test](registry/ouro/lib/ouro/testing/setup.test.ts "verify:testExists(registry/ouro/lib/ouro/testing/setup.test.ts::setup: the next test starts with the browser's media defaults)").
- Testing kit: `settled` waits until a popup or sheet has stopped moving, so a test presses where the item rests.
- Changed: the themes scan splits the light and dark schemes of its fixtures into separate test files, so CI shards run them side by side.
- Fixed: a Toolbar with `hidden` and `autoHide` [no longer starts a new rest when the app passes back the `hidden={false}` the bar asked for](registry/ouro/components/ouro/toolbar/toolbar.tsx "verify:testExists(registry/ouro/components/ouro/toolbar/toolbar.floating.test.tsx::Toolbar hidden > keeps the rest its own return started when the app passes hidden={false} back late)"), so it fades after `autoHide` however late the app renders; the app showing the bar itself still starts one.
