# Changes in this release

- Fixed: [an Alert with a title and an action but no description puts them on one line where they fit](registry/ouro/components/ouro/alert/alert.test.tsx "verify:testExists(registry/ouro/components/ouro/alert/alert.test.tsx::Alert > puts an action beside a title with no description where they fit, and under it where they don't)"), and the action under the title where they don't, as before; with a description the action stays under it.
- New: a shared `scripts/load.mjs` CPU-load harness (`withLoad`, `maxLoadWorkers`, `loadWorkersRemain`), so a lane proves a test's timing under contention with [no worker left running once the harness ends](scripts/load.test.mjs "verify:testExists(scripts/load.test.mjs::withLoad > runs fn while workers are alive, and leaves none running once it returns)"), including when [the harness process itself is killed](scripts/load.test.mjs "verify:testExists(scripts/load.test.mjs::withLoad > leaves no worker running when the harness process itself is killed with SIGTERM mid-run)") or [times out externally](scripts/load.test.mjs "verify:testExists(scripts/load.test.mjs::withLoad > leaves no worker running when the harness process times out externally)"), instead of a lane hand-rolling its own.
