# Changes in this release

- New: Ouro check's [`fragment-focus` rule](docs/guides/guardrails.md "verify:fileLine(docs/guides/guardrails.md, /fragment-focus. . A page with a stylesheet/)") names a page with stylesheets and [no fragmentFocusScript after them](test/check-in-page.test.ts "verify:testExists(test/check-in-page.test.ts::findFragmentFocusIssues > finds a page with a stylesheet and no fragmentFocusScript, marked on the page)"), where Safari takes focus as later stylesheets load on the page opened at a place on it; the installing guide says where the script goes in Vite and Next.js.
- New: AppWindow frames a live piece of interface as an application's window: a title bar with its label (such as the file a demo lives in) and actions such as a Code button, the working content inside, and the Ouro HX components it is built from as outline Badges in a "Built with" list along its foot ([test](registry/ouro/components/ouro/app-window/app-window.test.tsx "verify:testExists(registry/ouro/components/ouro/app-window/app-window.test.tsx::AppWindow > lists what it is built with along its foot, each name a list item and an outline Badge, under the label)")), with `inset={false}` for edge-to-edge content ([test](registry/ouro/components/ouro/app-window/app-window.test.tsx "verify:testExists(registry/ouro/components/ouro/app-window/app-window.test.tsx::AppWindow > pads the content by default, and runs it edge to edge with inset false)")).
- New: Avatar draws a group chat from its `members` (`<Avatar name="Crew" members={[{ name, src }]} />`): the person's squircle cut into slices of its members' pictures or initials, so a group chat no longer looks like a channel's `shape="square"`; ConversationList rows take `members` too.
