# Changes in this release

- Fixed: the vendored Button test of how `disabledReason` looks off no longer fails in an app whose theme draws a disabled solid button in its own colours at full opacity (`--ouro-action-disabled-opacity: 1`, as Spoonjoy's does). It now checks that a button off with `disabledReason` looks as a disabled one does, in [opacity, background, colour and cursor](registry/ouro/components/ouro/button/button.reason.test.tsx "verify:fileLine(registry/ouro/components/ouro/button/button.reason.test.tsx, /opacity: style.opacity, background: style.backgroundColor, color: style.color, cursor: style.cursor/)"), and that a disabled one looks different from one that is on, so it holds under any theme. CI now runs the looks-off tests under Spoonjoy's cookbook theme, with its disabled action tokens.
