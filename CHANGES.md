# Changes in this release

- Changed: a command's [`cliOnly` arg is left out of its MCP tool's input schema](registry/ouro/ax/mcp.test.mts "verify:testExists(registry/ouro/ax/mcp.test.mts::a word that only disambiguates the CLI's longer form is left out of the MCP schema, with every other property described)"), so an agent calling it over MCP sees only the properties that mean something there; the CLI still parses the word from a command line as before.
- Changed: a command whose CLI [streams forever is left out of the MCP tool list](registry/ouro/ax/mcp.test.mts "verify:testExists(registry/ouro/ax/mcp.test.mts::a command whose CLI streams forever is left out of the MCP tool list)"), since `tools/call` answers once and never a stream; mark one with `streams: true` on its `CommandDef`.
- New: [X-ray's MCP check fails a tool whose description promises a stream](registry/ouro/ax/xray.test.mts "verify:testExists(registry/ouro/ax/xray.test.mts::an MCP tool whose description promises a stream fails: this transport answers once per call, never a stream)"), since this transport answers once per call, never a stream, whatever the tool does underneath.
- Fixed: [Lightbox's Home and End jump through the carousel's own heading-tracked scroll instead of calling `scrollTo` on its own](registry/ouro/components/ouro/carousel/carousel.tsx "verify:testExists(registry/ouro/components/ouro/lightbox/lightbox.test.tsx::Lightbox viewer > shows the position a key or button chose before the scroll gets there, and announces it once it does)"), so a press right before or after one is never read against a stale or missing heading.
- Changed: TimeGrid draws its hour and half-hour lines as borders instead of a gradient.
- New: the Ouro AX X-ray checks a harness's in-turn tools (`--tools "<command>"`, JSON-RPC over stdio): `tools.*` claims in [claim set 1.9.0](registry/ouro/ax/ax-claims.ts "verify:fileLine(registry/ouro/ax/ax-claims.ts, /CLAIM_SET_VERSION = .1\.9\.0./)") for function definitions, a declared effect (must), a `when` line, a consequential tool's confirm question (must), bad calls refused naming the argument, typed outcomes whose codes the card lists, an unknown tool, and the inventory's `tools` list (must).
