# Changes in this release

- Changed: a windowed ConversationList [forces no layout read while it mounts](registry/ouro/components/ouro/conversation-list/conversation-list.windowing.test.tsx "verify:testExists(registry/ouro/components/ouro/conversation-list/conversation-list.windowing.test.tsx::ConversationList windowing > forces no layout while a windowed list mounts, and then sets its window from the observer's first callback)"); the resize observer's first callback finds the scroll container, measures the rows and sets the window.
- Changed: a windowed ConversationList's first view is [sized from the window's height (or the new `firstViewHeight` prop) in its first render](registry/ouro/components/ouro/conversation-list/conversation-list.windowing.test.tsx "verify:testExists(registry/ouro/components/ouro/conversation-list/conversation-list.windowing.test.tsx::ConversationList windowing with sections > renders its first view once, with no layout read in the mount commit, at the window's height)"), so it renders once and reads no layout before the first paint, where the 1.3.338 layout effect read layout and drew the list a second time; server HTML and a hydrating client keep 1000 pixels.
- New: [What is proven on a device](https://ui.ouroboros.bot/docs/platforms/proof/) says per platform where its checks run and what has not run on a device.
