# Changes in this release

- New: `Checklist` takes `ordered` (`true`, or the ids in order) for steps done in order: a step ticked before an earlier one turns the warning tone instead of done, names the step that comes first in a note it announces, and reads as done on its own once the earlier steps are ticked; `outOfOrderLabel` translates the note.
- Faster: [`useMediaQuery`, and the components that read a media query through it (HoverCard, Select, Tabs, `useReducedMotion` and others), call `matchMedia` once per query in a render](registry/ouro/lib/ouro/use-media-query.test.tsx "verify:testExists(registry/ouro/lib/ouro/use-media-query.test.tsx::useMediaQuery > calls matchMedia once for a query in a render, however many components read it)") and share that `MediaQueryList`, instead of making a new one for each component on each read, which a chat app measured in a long scroll on a slowed CPU; the next task asks again, so a change of the media still reads at once in WebKit.
