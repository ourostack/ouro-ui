# Changes in this release

- Fixed: a control off with `disabledReason` now looks as it does with `disabled`: [every Button variant, ReactionBar's reactions, SegmentedControl's segments and Tabs' tabs dim and show the not-allowed cursor](test/disabled-reason-look.test.tsx "verify:fileLine(test/disabled-reason-look.test.tsx, /a control off with disabledReason looks as it does with disabled/)"), so an app no longer needs its own CSS for them; a `loading` Button keeps its spinner and progress cursor without dimming.
- Fixed: [a Dialog or Sheet that closes while the next one opens no longer takes focus back from it, so Tab stays in the open one and does not reach the page behind](registry/ouro/components/ouro/dialog/dialog.sheet-overlap.test.tsx "verify:testExists(registry/ouro/components/ouro/dialog/dialog.sheet-overlap.test.tsx::an overlay opened while the one before it is still closing > keeps Tab inside the second sheet, and the page behind it hidden, after Escape on the first)"). A fast tap after Escape used to open a sheet whose focus leaked to the page behind it.
