# Changes in this release

- New: ButtonGroup takes `glass`, which draws its buttons inside one Liquid Glass capsule 40px tall with a divider between them, solid under reduced transparency or more contrast ([test](registry/ouro/components/ouro/button-group/button-group.glass.test.tsx "verify:testExists(registry/ouro/components/ouro/button-group/button-group.glass.test.tsx::ButtonGroup glass > is one capsule 40px tall with a rim, and its buttons sit flat inside it)")).
- Fix: Composer's rich editor no longer sometimes reverts `**bold**`/`_italic_` typed out to literal escaped Markdown; its value-sync effect runs in the same commit as the keystroke, not a later, racing one.
- Fixed: a MessageList [opened at a message before the newest stays there when its content is no more than 2px taller than the view](registry/ouro/components/ouro/message/message-list.test.tsx "verify:testExists(registry/ouro/components/ouro/message/message-list.test.tsx::MessageList > opened at a message before the newest, with the content 1px taller than the view, stays there instead of following the end)"), instead of following the end one frame after it draws and moving the message 1px.
- New: [`ouro-check watch` reruns the fast rules and the config's decisions against a running dev server](scripts/check/check-watch.test.mts "verify:testExists(scripts/check/check-watch.test.mts::Ouro check watch > watch reruns a running server's page and prints only the findings a run opened and closed, headless)"), headless, on a change or every few seconds, and prints only the findings a run opened and closed.
- Fixed: TimeGrid's placed events keep a symmetric inset from their day column's lines on both sides, since a multi-column view's shared borders need both sides clear of the doubled-line threshold.
- Fixed: TimeGrid's thin, borderless background bar events keep a minimal inset from their column's line instead of the wider inset full events use, since their narrow lane can't carry it.
