- Changed: an icon-only Button (one icon as its children and an `aria-label` or `aria-labelledby`, at size `sm`, `md` or `lg`) is as wide as it is tall, as shadcn's icon size is, so a theme whose controls are capsules draws it as a circle ([test](registry/ouro/components/ouro/button/button.test.tsx "verify:testExists(registry/ouro/components/ouro/button/button.test.tsx::icon-only size > is as wide as it is tall at size %s, with only an icon and a name)")); one with text, a start or end icon, no name or the inline size keeps its padding ([test](registry/ouro/components/ouro/button/button.test.tsx "verify:testExists(registry/ouro/components/ouro/button/button.test.tsx::icon-only size > keeps a label's padding where the icon has text beside it, a start icon, no name, or the inline size)")).
