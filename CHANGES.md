# Changes in this release

- New: `OuroProvider`'s `portalContainer` sets where Select, Menu, Combobox, Popover, Tooltip, HoverCard and NavigationMenu open their popups, so a `<div ref={popups} />` inside `<main>` keeps them in a landmark ([element or ref](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/portal-container.test.tsx "verify:testExists(registry/ouro/lib/ouro/portal-container.test.tsx::usePortalContainer > renders a popup into OuroProvider's portalContainer, given as a ref)"), [nested popups](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/portal-container.test.tsx "verify:testExists(registry/ouro/lib/ouro/portal-container.test.tsx::usePortalContainer > renders a popup opened from inside another popup into that popup's portal, not the portalContainer)")).
- New: `portalContainer={null}` on an inner `OuroProvider` gives popups Base UI's own place again, for a dialog the app draws itself ([test](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/portal-container.test.tsx "verify:testExists(registry/ouro/lib/ouro/portal-container.test.tsx::usePortalContainer > gives popups Base UI's own place again inside an OuroProvider whose portalContainer is null, as an app's own dialog needs)")).
- New: in development, a popup that opens outside every landmark of a page with a `<main>` warns once with that fix ([warning](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/portal-container.test.tsx "verify:testExists(registry/ouro/lib/ouro/portal-container.test.tsx::usePortalContainer > warns once, in development, when a popup opens outside every landmark of a page that has a main)")).
- Fix: Inspector's X-ray outlines step around text and its name tags sit clear of text and of each other, and its bar is a region named by its label ([readable text](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/components/ouro/inspector/inspector.test.tsx "verify:testExists(registry/ouro/components/ouro/inspector/inspector.test.tsx::Inspector > leaves every line of the page's text as readable as it was, in light and dark: outlines step around text, and tags sit clear of text and of each other)"), [landmark](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/components/ouro/inspector/inspector.test.tsx "verify:testExists(registry/ouro/components/ouro/inspector/inspector.test.tsx::Inspector > puts its bar in a landmark named by its label)")).
- Fix: an open Combobox list no longer hides the rest of the page from screen readers ([test](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/components/ouro/combobox/combobox.test.tsx "verify:testExists(registry/ouro/components/ouro/combobox/combobox.test.tsx::Combobox > leaves the rest of the page exposed while its list is open, so the gate passes from the page's main landmark)")).
- Fix: Command hides its empty list while nothing matches, leaving only the empty state ([test](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/components/ouro/command/command.test.tsx "verify:testExists(registry/ouro/components/ouro/command/command.test.tsx::Command > hides the empty list from assistive technology while nothing matches, so the gate passes with only the empty state)")).
- Fix: SidebarLayout's `header` renders in a `<header>`, the page's banner landmark ([test](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/components/ouro/sidebar/sidebar-layout.test.tsx "verify:testExists(registry/ouro/components/ouro/sidebar/sidebar-layout.test.tsx::SidebarLayout > puts the header in the page's banner landmark, and draws no empty landmark without one)")).
- Fix: Chart's axis labels use the theme's muted text color again, not recharts' gray, which failed contrast in dark mode ([test](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/components/ouro/chart/chart.test.tsx "verify:testExists(registry/ouro/components/ouro/chart/chart.test.tsx::Chart > writes the axis labels in the theme's muted text color, not recharts' gray, in light and dark)")).
- New: `audit` in `testing/axe` fails every violation at any impact and every result axe could not decide unless it measures it, in both color schemes; it measures text contrast from screenshots, including SVG text, letters set on a curve, decorative text hidden from assistive technology and text under open popups ([any impact](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/testing/axe.test.ts "verify:testExists(registry/ouro/lib/ouro/testing/axe.test.ts::audit > fails a violation whatever its impact: content outside every landmark is only moderate)"), [measured contrast](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/testing/axe.test.ts "verify:testExists(registry/ouro/lib/ouro/testing/axe.test.ts::audit > passes text over a gradient when every pixel behind it meets 4.5:1, and fails faint text over the same gradient)"), [curve](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/testing/axe.test.ts "verify:testExists(registry/ouro/lib/ouro/testing/axe.test.ts::audit > measures letters set on a curve against what is behind each turned letter, not the box around it)"), [hidden text](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/testing/axe.test.ts "verify:testExists(registry/ouro/lib/ouro/testing/axe.test.ts::audit > measures text the page hides from assistive technology that lets the pointer through, as decorative lettering does)")).
- Fix: `claims-check.mjs lint --pr` and `--stdin` fetch a link that only the pull request's text cites, instead of asking for a cache entry the full check then rejects ([test](https://github.com/ourostack/ouro-ui/blob/main/scripts/claims.test.mjs "verify:testExists(scripts/claims.test.mjs::the lint command fetches a link that only a pull request's text cites, and leaves the URL cache alone)")).
- Fix: ColorSchemeToggle's tests wait for the menu to open and for the page to switch before checking it ([test](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/components/ouro/color-scheme-toggle/color-scheme-toggle.test.tsx "verify:testExists(registry/ouro/components/ouro/color-scheme-toggle/color-scheme-toggle.test.tsx::ColorSchemeToggle > switches the page without a provider)")).
- Fix: a Link in running text marks keyboard focus with a thick underline in the ring's color, instead of an outline that covered the next character, such as a comma ([test](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/components/ouro/link/link.test.tsx "verify:testExists(registry/ouro/components/ouro/link/link.test.tsx::Link > marks keyboard focus in running text with a thick underline in the ring's colour, not an outline drawn over the next character)")).
- Fix: the docs' prop and parameter tables show only the columns they fill, and a page has no empty table ([test](https://github.com/ourostack/ouro-ui/blob/main/scripts/gen-docs.test.mjs "verify:testExists(scripts/gen-docs.test.mjs::a parameter or prop table has only the columns it fills, and there is no table without rows)")).
