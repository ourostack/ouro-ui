# Changes in this release

- Changed: web vendors [core v0.19.0](test/fixtures/a2ui/core.json "verify:equals(test/fixtures/a2ui/core.json#coreTag)=v0.19.0"), whose `applyTreeUpdate` changes a composed tree by node id and its data by JSON pointer ([the decision record](https://github.com/ourostack/ouro-ui-core/blob/c90da442be466dfd0f80b435c3a44d3c175c6092/docs/decisions/2026-11-18-composed-tree-updates.md "verify:urlOk(https://github.com/ourostack/ouro-ui-core/blob/c90da442be466dfd0f80b435c3a44d3c175c6092/docs/decisions/2026-11-18-composed-tree-updates.md)")). `OuroMcpApp` applies a tool result whose `structuredContent.ouro` carries `update` to the tree it shows; an update that can't apply shows the same short alert as a tree that fails the checks, and the agent hears why.
- Changed: `ComposedSurface` and `A2UISurface` keep what the person entered when the tree, the data or the messages change, except where the new data changed the value, or the list item it is in, where the agent's value wins; before, new data started the fields over.
- Changed: from [core v0.18.3](https://github.com/ourostack/ouro-ui-core/releases/tag/v0.18.3 "verify:urlOk(https://github.com/ourostack/ouro-ui-core/releases/tag/v0.18.3)") on, which web vendors, core's tree validator refuses a confirm sheet that shows the person one value and sends another ([ourostack/ouro-ui-core#88](https://github.com/ourostack/ouro-ui-core/issues/88 "verify:urlOk(https://github.com/ourostack/ouro-ui-core/issues/88)")). It also refuses a button input the catalog's action doesn't declare, and an app's `label` resolver now names only id fields, those whose catalog input has `shownAs`: give an id field `shownAs` to keep its name on the confirm sheet. A name the agent chooses is the catalog's only when the catalog itself has it, and a data-model pointer never reaches an object's prototype ([ourostack/ouro-ui-core#91](https://github.com/ourostack/ouro-ui-core/issues/91 "verify:urlOk(https://github.com/ourostack/ouro-ui-core/issues/91)")).
- Fixed: Ouro check's `cramped-heading` rule counts a flex row's own padding as room above its heading, so a heading with its text well clear of a box above it, on a row with top padding, is no longer reported as cramped.
- New: `ouro-feel-probe`, Ouro Feel's probe as one plain script (`scripts/ouro/feel/ouro-feel-probe.js`), so an app adds it at a release tag with `npx shadcn@latest add ourostack/ouro-ui/ouro-feel-probe#<tag>` and puts it first in the page or its web view.
