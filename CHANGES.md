# Changes in this release

- New: A2UISurface shows the UI an agent composed in A2UI with Ouro HX. Its buttons are your declared actions, and pressing one follows its consent class.
- Changed: /adoption/ leads with its target, the products more than a day behind an Ouro UI release, and gives the total releases behind as context.
- Changed: the Platforms pages, the parity matrix, the README and llms.txt name Android's first kit, ouro-ui-android, which is checked on emulators only.
- Changed: the Apple pages and the Platforms pages name Apple's release with `OuroBadge`, `OuroCard` and `OuroItem`.
- Changed: the Apple pages and the Platforms pages name the current Apple release.
- Changed: an avatar's team edge is a shadow offset from the box, and an agent without an icon or picture shows a sparkle in its hue instead of an initial.
- Changed: an avatar's presence dot is now bitten out of the avatar, so the background shows through the gap round it; a team's edge still reads `--ouro-avatar-ring`.
- Avatars: a person is a squircle, a team a squircle with a second edge behind it, and an AI agent a less-rounded white tile with a presence dot, replacing the hexagon (`shape="agent"` is new, `shape="hexagon"` is gone).
- New: the [Ouro AX guide](docs/guides/ax.md#when-a-page-asks-to-open-an-app) says what an agent surface that drives a browser does when a page tries to open a desktop app: refuse it the same way on any site, follow the page's own web option by role and name, and report which app was refused, what it did instead and the next command.
- New: Ouro AX's flags can [repeat](registry/ouro/ax/command.test.mts "verify:testExists(registry/ouro/ax/command.test.mts::a repeat flag collects each value in order, in either form, and is absent when not given)"), so `--ready a --ready b` gives a list.
