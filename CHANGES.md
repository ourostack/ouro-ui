- New: A2UISurface's confirm sheet shows an id's name as the row, with the id [small beside it](registry/ouro/components/ouro/a2ui-surface/a2ui-surface.test.tsx "verify:testExists(registry/ouro/components/ouro/a2ui-surface/a2ui-surface.test.tsx::A2UISurface > shows a confirm row's name, with its id small beside it, and a row with no name shows its value alone)"), and takes a `label` resolver that [names ids from the app's own data](registry/ouro/components/ouro/a2ui-surface/a2ui-surface.test.tsx "verify:testExists(registry/ouro/components/ouro/a2ui-surface/a2ui-surface.test.tsx::A2UISurface > passes the app's resolver each confirm row's id, and shows the name it gives)"). It adopts core v0.9.0's [confirm-names case](test/fixtures/a2ui/core.json "verify:fileLine(test/fixtures/a2ui/core.json, /cases\/confirm-names\.json/)").
- New: A2UISurface shows the UI an agent composed in A2UI with Ouro HX. Its buttons are your declared actions, and pressing one follows its consent class.
- Changed: Accordion panels open with a CSS grid row instead of Base UI measuring them, so closed items skip style and layout work when they mount.
- Changed: /adoption/ leads with its target, the products more than a day behind an Ouro UI release, and gives the total releases behind as context.
- Changed: the Platforms pages, the parity matrix, the README and llms.txt name Android's first kit, ouro-ui-android, which is checked on emulators only.
- Changed: the Apple pages and the Platforms pages name Apple's release with `OuroBadge`, `OuroCard` and `OuroItem`.
- Changed: the Apple pages and the Platforms pages [name Apple's 0.8.0](site/src/apple/kit.json "verify:equals(site/src/apple/kit.json#release)=0.8.0"), and the parity table lists [each view a Swift file declares](scripts/parity-matrix.test.mjs "verify:fileLine(scripts/parity-matrix.test.mjs, /counts each, and not its support types/)"), so `OuroSkeleton`, `OuroSpinner` and `OuroProgress` all show.
- Changed: the Apple pages and the Platforms pages name the current Apple release.
- Changed: an avatar's team edge is a shadow offset from the box, and an agent without an icon or picture shows a sparkle in its hue instead of an initial.

- New: the [Ouro AX guide](docs/guides/ax.md#when-a-page-asks-to-open-an-app) says what an agent surface that drives a browser does when a page tries to open a desktop app: refuse it the same way on any site, follow the page's own web option by role and name, and report which app was refused, what it did instead and the next command.
- New: Ouro AX's command [names its exit code](registry/ouro/ax/cli.test.mts "verify:testExists(registry/ouro/ax/cli.test.mts::a data result exits with the code its command names in the tool's table, and --json prints the data unchanged)").
