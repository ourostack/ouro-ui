# Changes in this release

- New: A2UISurface's confirm sheet shows an id's name as the row, with the id [small beside it](registry/ouro/components/ouro/a2ui-surface/a2ui-surface.test.tsx "verify:testExists(registry/ouro/components/ouro/a2ui-surface/a2ui-surface.test.tsx::A2UISurface > shows a confirm row's name, with its id small beside it, and a row with no name shows its value alone)"), and takes a `label` resolver that [names ids from the app's own data](registry/ouro/components/ouro/a2ui-surface/a2ui-surface.test.tsx "verify:testExists(registry/ouro/components/ouro/a2ui-surface/a2ui-surface.test.tsx::A2UISurface > passes the app's resolver each confirm row's id, and shows the name it gives)"). It adopts core v0.9.0's [confirm-names case](test/fixtures/a2ui/core.json "verify:fileLine(test/fixtures/a2ui/core.json, /cases\/confirm-names\.json/)").
- Changed: Accordion panels open with a CSS grid row instead of Base UI measuring them, so closed items skip style and layout work when they mount.
- Changed: Avatar draws a person with rounder corners so a person reads apart from a team, and its presence dot sits on the edge of the curve with the avatar cut away round it, a plain colour on the small sizes and with its glyph on the larger ones.
- New: Ouro AX's command [names its exit code](registry/ouro/ax/cli.test.mts "verify:testExists(registry/ouro/ax/cli.test.mts::a data result exits with the code its command names in the tool's table, and --json prints the data unchanged)"). A command that returns data takes `exit`, a name from the tool's exit table, so `--json` prints the data as before and the process exits with that code; a name the table does not have is refused.
- Ouro AX: `didYouMean` tries the nearest name first, then a unique prefix, so `--n` suggests `--in` rather than `--names`.
- New: Ouro AX's `defineCli` takes `command` for a tool with one thing to do, which [runs with no command word](registry/ouro/ax/command.test.mts "verify:testExists(registry/ouro/ax/command.test.mts::a tool with one command reads every token as the command's arguments and flags, with no command word)"): `ouro-images <folder>`. A tool with `commands` still refuses a word it doesn't know.
- Fixed: the baked-corner check no longer flags a picture whose own glow or shading near its corners wanders in colour; only a flat fill baked into the corners is flagged.
- New: Button names its tone in [data-tone](registry/ouro/components/ouro/button/button.test.tsx "verify:testExists(registry/ouro/components/ouro/button/button.test.tsx::button branch > names its tone in data-tone, on buttons and links, so one tone's look is compared with itself)"), beside data-variant, so an app's rules and the site's sameness sweep can tell tones apart.
- Card: a linked card takes `zoomMedia`, which grows its pictures a little inside their frame while the pointer rests on it or keyboard focus is in it (not with reduced motion), and `revealDescription`, which keeps its description back until then on a screen with a mouse; on a touch screen the description shows from the start, and the link names it as its description.
- Fixed: Ouro check passes a radial mask that cuts a hard-edged hole in a picture (Avatar bite) and still flags a mask that fades the edge.
- New: Ouro check's gated `hero-dark-art` rule [finds a Hero with no night art](test/check-theme-in-page.test.ts "verify:testExists(test/check-theme-in-page.test.ts::findThemeIssues: hero-dark-art > finds a hero whose picture has no night art, in light mode too, named by its words)"), a picture in its frame with no dark twin, so an app that shows the day scene in dark mode fails the check until it passes `picture={{ light, dark }}`.
- Changed: `ouro-check` runs on [Ouro AX](registry/ouro/ax/command.test.mts "verify:testExists(registry/ouro/ax/command.test.mts::a tool with one command reads every token as the command's arguments and flags, with no command word)"), with `merge` beside it as a command word, so its `--help` and `--json` come from the kit. A refused option or target prints [one line that ends with the fix](scripts/check/check.test.mts "verify:testExists(scripts/check/check-command.test.mts::Ouro check's command > refuses a target that is no folder or URL in one line that names the fix, and a mistyped merge names merge)"), and [exits 2](scripts/check/check.test.mts "verify:testExists(scripts/check/check-command.test.mts::Ouro check's command > prints the kit's help for --help, and refuses an unknown flag in one line that names its fix, with exit 2)"). Gated findings still [exit 3](scripts/check/check.test.mts "verify:testExists(scripts/check/check-command.test.mts::Ouro check's command > exits 3 on gated findings, writes the step summary, and exits 0 when the config waives them)"). It now installs to [`@lib/ouro/check/`](scripts/registry.mts "verify:fileLine(scripts/registry.mts, /@lib\/ouro\/check\//)"), beside the kit it imports, where it was `~/lib/ouro/check/`.
- Fixed: Ouro check's nested-frame rule skips a component's own surface layer (`data-ouro-surface`, `data-ouro-avatar-surface`) and keeps checking its real children, which fixes Button, Card, Dialog and TextField in browsers without corner-shape.
- Changed: The claims linter no longer reads issue and pull request references, GitHub run and job IDs, commit SHAs, or a digit inside a word, as numbers, and no longer reads "no longer" as a negative. `pnpm claims:lint --pr` takes `--title` and `--body-file`, and lints the change fragments its branch adds.
- Collapsible [reads no style or layout when it mounts](registry/ouro/components/ouro/collapsible/collapsible.test.tsx "verify:testExists(registry/ouro/components/ouro/collapsible/collapsible.test.tsx::Collapsible > reads no style or layout when it mounts closed, however many there are)"): its panel is Ouro's own CSS-driven one, not Base UI's, so a page of closed Collapsibles mounts without a forced reflow.
- New: ComposedSurface draws Ouro's composed tree, core's format-neutral ComposedNode, with Ouro HX. A2UISurface now resolves A2UI messages into that tree and draws it with ComposedSurface's renderer.
- Fixed: Mounting a ToggleGroup skips Base UI composite's per-item style check, which forced a style recalculation.
- Fixed: ConversationList sizes its first frame for short rows, so a list of short rows adds nothing after the first paint.
- Fixed: ConversationList counts its first frame's rows from the estimates alone and adds overscan on the first scroll or size change, so frame one holds the rows the settled screen holds.
- Fixed: a windowed ConversationList lays its first rows out in normal flow, so [no row or header moves after the first painted frame](registry/ouro/components/ouro/conversation-list/conversation-list.windowing.test.tsx "verify:testExists(registry/ouro/components/ouro/conversation-list/conversation-list.windowing.test.tsx::ConversationList windowing with sections > keeps every element where frame one put it, for rows and headers shorter than the estimates, in sections of mixed sizes)").
- ConversationList: a row's `where` (the muted name after its title) [shows whole or not at all](registry/ouro/components/ouro/conversation-list/conversation-list.test.tsx "verify:testExists(registry/ouro/components/ouro/conversation-list/conversation-list.test.tsx::ConversationList > shows the where whole or not at all, never cut, and gives it up before the title)"): when the row has no room for it, it is hidden rather than cut to a fragment, and screen readers still read it.
