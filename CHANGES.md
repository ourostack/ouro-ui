# Changes in this release

- Changed: an icon-only Button sizes its svg child as it sizes `startIcon` unless the icon has a size class of its own, so a Lucide icon matches `startIcon` instead of keeping its own fixed size, and an icon without a size is drawn.
- Fixed: a Carousel that is drawn scaled when it mounts, as a Lightbox viewer is while it opens, starts on the slide it was given: it used to land a slide short or long of it, so a Lightbox opened on a late image showed the wrong one ([test](registry/ouro/components/ouro/carousel/carousel.test.tsx "verify:testExists(registry/ouro/components/ouro/carousel/carousel.test.tsx::Carousel inside a scaled element > starts on defaultIndex when it mounts under a transform, as a Lightbox viewer does while it opens)")).
- Fixed: Lightbox's shipped loop spec [presses Next once the viewer has grown from the thumbnail](registry/ouro/e2e/ouro/lightbox.spec.ts "verify:fileLine(registry/ouro/e2e/ouro/lightbox.spec.ts, /await settledBox\(next\);/)"), since a press while it still grew could end off the button in WebKit.
- Fixed: MessageList waits for the wheel to rest before it corrects a small drift of the reader's place, so WebKit's scroll keeps moving while older history loads.
- Changed: Skeleton's shimmer moves a band with a transform instead of animating the background, so a page with skeletons can rest between frames.
- Fixed: the testing kit's `commands.emulateMedia` [returns once the test frame matches the preference it set](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/testing/commands.test.ts "verify:testExists(registry/ouro/lib/ouro/testing/commands.test.ts::emulateMedia returns once the frame matches the preference, so the next line reads its styles)"), so a test can read the new styles on its next line.
- Fixed: Toolbar's shipped fade spec lets the held clock run until the tooltip has gone, [instead of reading the tooltip after a set run of the clock](registry/ouro/e2e/ouro/toolbar.spec.ts "verify:fileLine(registry/ouro/e2e/ouro/toolbar.spec.ts, /await page.clock.resume\(\);/)"), which failed at random in WebKit.
- Fixed: a Toolbar's tooltip closes in the same update that fades the bar, so [the bar fades out with its tooltip already closed](registry/ouro/e2e/ouro/toolbar.spec.ts "verify:testExists(registry/ouro/e2e/ouro/toolbar.spec.ts::fades after the pointer rests, stays reachable, and comes back on a move over the stage or when Tab reaches it)").
