# Changes in this release

- Fixed: MessageList's windowing reads a row's box again only once a resize observer catches it changing, leaving every other row at its cached size, so [a short row above the view that grows with no DOM mutation at all, as an image or font settling its own size does, no longer moves the reader off their place](registry/ouro/components/ouro/message/message-list.windowing.test.tsx "verify:testExists(registry/ouro/components/ouro/message/message-list.windowing.test.tsx::MessageList windowing > holds the reader's place once a row above the view grows with nothing in the list mutated at all, as a font load finishing would (#2863))"), and [an untouched row beside a scroll that shifts the drawn window is never read fresh](registry/ouro/components/ouro/message/message-list.windowing.test.tsx "verify:testExists(registry/ouro/components/ouro/message/message-list.windowing.test.tsx::MessageList windowing > reads a row's box again only once a resize observer reports it changed, leaving one beside it unresized at its cached size, over a scroll that shifts the window (#2863))").
- Fixed: [MessageList no longer crashes when a message remounts a different element under the same key and a resize notification for the old, already-removed element arrives afterward](registry/ouro/components/ouro/message/message-list.actions.test.tsx "verify:testExists(registry/ouro/components/ouro/message/message-list.actions.test.tsx::MessageList actions > settles on the real height of a slot whose message remounts under the same key, not a stale cache)").
- Fixed: [`audit` from the test kit scans the page once it has painted](registry/ouro/lib/ouro/testing/axe.test.ts "verify:testExists(registry/ouro/lib/ouro/testing/axe.test.ts::audit > scans the page as first painted: a scrolling region a resize report makes a tab stop passes, one that never becomes one fails)"), so a test that audits as soon as its render returns no longer fails `scrollable-region-focusable` on a ScrollArea, or a TimeGrid, that becomes a tab stop before its first paint.
- New: [TimeGrid `markedDays` tints a day's column from its header to its last hour, such as the days someone is out of office, and shows why in words](registry/ouro/components/ouro/time-grid/time-grid.test.tsx "verify:testExists(registry/ouro/components/ouro/time-grid/time-grid.test.tsx::TimeGrid > tints a marked day's column from its header to its last hour, and says why in words)").
