# Changes in this release

- Fixed: TimeGrid's slot preview is left off where one of the person's own events covers the slot, so its text never draws under an event card, and where a background event is it starts past the background lane, so it still shows ([test](registry/ouro/components/ouro/time-grid/time-grid.test.tsx "verify:fileLine(registry/ouro/components/ouro/time-grid/time-grid.test.tsx, /shows no preview where one of the person's own events would cover the slot/)"), [lane test](registry/ouro/components/ouro/time-grid/time-grid.test.tsx "verify:fileLine(registry/ouro/components/ouro/time-grid/time-grid.test.tsx, /shows the preview past the background lane/)")).
- Changed: Command's palette fades and scales in and out like Dialog, [from 0.96 on the same tokens](registry/ouro/components/ouro/command/command.test.tsx "verify:testExists(registry/ouro/components/ouro/command/command.test.tsx::Command motion > fades and scales in from 0.96 on the Dialog's slow token, and only fades with reduced motion)"); with reduced motion it only fades, as Dialog does.
- New: Ouro check ships [`new-rules.json`, the rules a release adds with a line saying what each finds](scripts/check/check-command.test.mts "verify:testExists(scripts/check/check-command.test.mts::Ouro check's command > new-rules.json names rules Ouro check has, each once, with a one-line summary, for Ouro Current to list in an update)"), which Ouro Current lists in an app's update pull request; `off-theme` and `off-scale` are the first.
- Changed: an Ouro check `first-paint-swap` finding [gives both controls' HTML, as first drawn and at rest](test/check-measure.test.ts "verify:testExists(test/check-measure.test.ts::findLoadingIssues: first-paint-swap > reports a control a later frame drew over the place of one the first frame drew, with no input, once)"), in `report.json`'s `swap`.
- New: `Item` takes `onSelect`, which makes the whole row [one button named by its title](registry/ouro/components/ouro/item/item.test.tsx "verify:testExists(registry/ouro/components/ouro/item/item.test.tsx::Item with onSelect > is one button named by its title, covering the row, that calls onSelect, with the actions above it)"), for a list beside its detail, and `selected`, which marks the row shown (`aria-current`) in the selected colour, on a button row or a link row.
- Fixed: Ouro Current adds a `@keyframes` or `@utility` block from `ouro-base` that the app's stylesheet has no block of that name for, also when the app's pins already name the newest release, and keeps one of that name the app has as the app wrote it ([test](scripts/current/current.test.mjs "verify:testExists(scripts/current/current.test.mjs::an app on the newest release whose stylesheet lacks a keyframes ouro-base has gets the stylesheet update adding that block alone, and a second run is current)")).
- Changed: Ouro Current's list of new Ouro check rules gives a rule's count of the app's findings recorded as known, in place of a day the rule gates from, and names the recorded rules when the release lacks `new-rules.json`.
