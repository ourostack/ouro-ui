# Changes in this release

- Changed: `ouro-check` runs on [Ouro AX](registry/ouro/ax/command.test.mts "verify:testExists(registry/ouro/ax/command.test.mts::a tool with one command reads every token as the command's arguments and flags, with no command word)"), with `merge` beside it as a command word, so its `--help` and `--json` come from the kit. A refused option or target prints [one line that ends with the fix](scripts/check/check.test.mts "verify:testExists(scripts/check/check-command.test.mts::Ouro check's command > refuses a target that is no folder or URL in one line that names the fix, and a mistyped merge names merge)"), and [exits 2](scripts/check/check.test.mts "verify:testExists(scripts/check/check-command.test.mts::Ouro check's command > prints the kit's help for --help, and refuses an unknown flag in one line that names its fix, with exit 2)"). Gated findings still [exit 3](scripts/check/check.test.mts "verify:testExists(scripts/check/check-command.test.mts::Ouro check's command > exits 3 on gated findings, writes the step summary, and exits 0 when the config waives them)"). It now installs to [`~/scripts/ouro/check/`](scripts/registry.mts "verify:fileLine(scripts/registry.mts, /~\/scripts\/ouro\/check\//)"), outside the app's TypeScript project, where it was `~/lib/ouro/check/`.
- Changed: `ouro-images` runs on [Ouro AX](registry/ouro/ax/command.test.mts "verify:testExists(registry/ouro/ax/command.test.mts::a tool with one command reads every token as the command's arguments and flags, with no command word)"), so its `--help` and `--json` come from the kit. A refused option prints one line that ends with the fix to run and [exits 2](scripts/images/images.test.mts "verify:testExists(scripts/images/images.test.mts::Ouro images' command > refuses what it cannot run with one line that names the fix, and exits 2)"). It now installs to [`~/scripts/ouro/images/`](scripts/registry.mts "verify:fileLine(scripts/registry.mts, /~\/scripts\/ouro\/images\//)"), outside the app's TypeScript project, where it was `~/lib/ouro/images/`.
- Changed: Ouro check, Ouro images, and the X-ray, flow runner and surfaces check with their tests install under `scripts/ouro/`, outside your TypeScript project, so `tsc -b` no longer reads their Node imports ([the type check](scripts/check-vite-types.test.mjs "verify:testExists(scripts/check-vite-types.test.mjs::a Vite app type-checks with Ouro check and Ouro images installed where the CLI puts them, outside src, and fails with their Node files in src)")); they import the Ouro AX kit as `#ouro-ax/<file>`, which `npm pkg set "imports.#ouro-ax/*=./src/lib/ouro/ax/*"` adds to package.json once.
