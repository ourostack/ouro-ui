# Changes in this release

- Changed: a windowed ConversationList [forces no layout read while it mounts beyond the first view's](registry/ouro/components/ouro/conversation-list/conversation-list.windowing.test.tsx "verify:testExists(registry/ouro/components/ouro/conversation-list/conversation-list.windowing.test.tsx::ConversationList windowing > forces no layout but the first view's while a windowed list mounts, and then sets its window from the observer's first callback)"); the resize observer's first callback finds the scroll container, measures the rows and sets the window.
- Changed: a windowed ConversationList's first frame mounts [only the rows the list's own height shows](registry/ouro/components/ouro/conversation-list/conversation-list.windowing.test.tsx "verify:testExists(registry/ouro/components/ouro/conversation-list/conversation-list.windowing.test.tsx::ConversationList windowing with sections > mounts only the rows the list's own height shows on the first frame, with each row's position and the set's size intact, and no blank at the first scroll)"), not 1000 pixels of them; server HTML still renders 1000 pixels, a layout effect narrows the first client frame before it paints, and `aria-posinset` and `aria-setsize` still give the full count.
