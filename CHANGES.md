# Changes in this release

- New: Ouro AX's flags can [repeat](registry/ouro/ax/ax-command.test.mts "verify:testExists(registry/ouro/ax/ax-command.test.mts::a repeat flag collects each value in order, in either form, and is absent when not given)"), so `--ready a --ready b` gives a list. A tool can define [a default command beside its named commands](registry/ouro/ax/ax-command.test.mts "verify:testExists(registry/ouro/ax/ax-command.test.mts::defineCli needs command or commands, and takes both: the default beside the named commands)"), which [runs when no command word leads](registry/ouro/ax/ax-command.test.mts "verify:testExists(registry/ouro/ax/ax-command.test.mts::a tool with a default command runs it for any leading word that is not a command word, and a command word goes after --)").
- Fixed: Ouro AX names an argument's choices in plain words when it refuses a word outside them, and its Fix, and an enum flag's, is a command an agent can run as it stands, with the closest choice or else the first (`shepherd: sidebar: it takes plan or apply, not "sweep". Fix: shepherd sidebar plan.`), not a placeholder and a list (`<action> is one of plan, apply` and `shepherd sidebar "plan|apply"`) ([test](registry/ouro/ax/ax-command.test.mts "verify:testExists(registry/ouro/ax/ax-command.test.mts::a refused word's Fix is a command an agent can run as it stands, and the problem names the choices in plain words)")).
- New: Ouro AX's `defineCli` takes `command` for a tool with one thing to do, which [runs with no command word](registry/ouro/ax/ax-command.test.mts "verify:testExists(registry/ouro/ax/ax-command.test.mts::a tool with one command reads every token as the command's arguments and flags, with no command word)"): `ouro-images <folder>`. A tool with `commands` still refuses a word it doesn't know.
- Fixed: [an Ouro AX command other people see asks for `--why` before it refuses a word outside an argument's values](registry/ouro/ax/ax-command.test.mts "verify:testExists(registry/ouro/ax/ax-command.test.mts::a command other people see asks for --why before it refuses a word outside an argument's values, as ax-xray's probe expects)"), so ax-xray's `cli.others-need-why` passes on a command whose argument has values.
- Changed: `ouro-check` runs on [Ouro AX](registry/ouro/ax/ax-command.test.mts "verify:testExists(registry/ouro/ax/ax-command.test.mts::a tool with one command reads every token as the command's arguments and flags, with no command word)"), with `merge` beside it as a command word, so its `--help` and `--json` come from the kit. A refused option or target prints [one line that ends with the fix](scripts/check/check.test.mts "verify:testExists(scripts/check/check-command.test.mts::Ouro check's command > refuses a target that is no folder or URL in one line that names the fix, and a mistyped merge names merge)"), and [exits 2](scripts/check/check.test.mts "verify:testExists(scripts/check/check-command.test.mts::Ouro check's command > prints the kit's help for --help, and refuses an unknown flag in one line that names its fix, with exit 2)"). Gated findings still [exit 3](scripts/check/check.test.mts "verify:testExists(scripts/check/check-command.test.mts::Ouro check's command > exits 3 on gated findings, writes the step summary, and exits 0 when the config waives them)"). It now installs to [`~/scripts/ouro/check/`](scripts/registry.mts "verify:fileLine(scripts/registry.mts, /~\/scripts\/ouro\/check\//)"), outside the app's TypeScript project, where it was `~/lib/ouro/check/`.
- ImageCropper: fixed sizes (the zoom slider's maximum width) read `--ouro-size-*` tokens, so a compact `--spacing` no longer shrinks them (#417).
- Changed: `ax-flows run` runs on [Ouro AX](registry/ouro/ax/ax-command.test.mts "verify:testExists(registry/ouro/ax/ax-command.test.mts::a tool with one command reads every token as the command's arguments and flags, with no command word)"), so its `--help` and `--json` come from the kit. A refused option or suite module prints [one line that ends with the fix](registry/ouro/ax/flows.test.mts "verify:testExists(registry/ouro/ax/flows.test.mts::the command's --help is the Ouro AX kit's, and an unknown flag is one line that names the fix, exit 2)"), and under `--json` stdout holds [the outcome alone](registry/ouro/ax/flows.test.mts "verify:testExists(registry/ouro/ax/flows.test.mts::--json prints the outcome alone on stdout, and each flow's line on stderr)").
- Changed: `ouro-images` runs on [Ouro AX](registry/ouro/ax/ax-command.test.mts "verify:testExists(registry/ouro/ax/ax-command.test.mts::a tool with one command reads every token as the command's arguments and flags, with no command word)"), so its `--help` and `--json` come from the kit. A refused option prints one line that ends with the fix to run and [exits 2](scripts/images/images.test.mts "verify:testExists(scripts/images/images.test.mts::Ouro images' command > refuses what it cannot run with one line that names the fix, and exits 2)"). It now installs to [`~/scripts/ouro/images/`](scripts/registry.mts "verify:fileLine(scripts/registry.mts, /~\/scripts\/ouro\/images\//)"), outside the app's TypeScript project, where it was `~/lib/ouro/images/`.
- New: [`useLoadingVisible` times a loading placeholder: it shows only once a load has run for 200ms and stays for 500ms once shown](registry/ouro/lib/ouro/use-loading-visible.test.tsx "verify:testExists(registry/ouro/lib/ouro/use-loading-visible.test.tsx::useLoadingVisible > keeps a shown placeholder until it has been up for the minimum, then hides it)"), ready to wrap a `Skeleton` or any placeholder.
- Changed: Ouro AX's `command.ts` is now `ax-command.ts` and its `claims.ts` is now `ax-claims.ts`, and ouro-check's `register.ts` is now `check-register.ts`, so no two Ouro files share a name and [shadcn resolves each import to its own file](scripts/registry.test.mjs "verify:testExists(scripts/registry.test.mjs::no two files an item ships share a base name, so shadcn resolves each import to its own file)") (#2757). Change your imports from `#ouro-ax/command.ts` to `#ouro-ax/ax-command.ts` and from `#ouro-ax/claims.ts` to `#ouro-ax/ax-claims.ts`.
