# Changes in this release

- MessageList: while the wheel turns, older messages going in above are held by drawing the content that far up (a `translate`), [and the scroll position takes it in one move once the wheel rests](registry/ouro/components/ouro/message/message-list.windowing.test.tsx "verify:testExists(registry/ouro/components/ouro/message/message-list.windowing.test.tsx::MessageList windowing > holds growth above the reader without writing the scroll position while the wheel turns, a page's worth too, and pays it once the wheel rests)") [or as the reader nears either end](registry/ouro/components/ouro/message/message-list.windowing.test.tsx "verify:testExists(registry/ouro/components/ouro/message/message-list.windowing.test.tsx::MessageList windowing > pays what it holds as the reader nears either end, so what went in above is in reach while the wheel still turns)"), so WebKit's own wheel scroll keeps moving and the messages above stay in reach.
- Fixed: SyncStatus's Retry [takes the sentence's face, size and line height](registry/ouro/components/ouro/sync-status/sync-status.tsx "verify:testExists(registry/ouro/components/ouro/sync-status/sync-status.test.tsx::SyncStatus > sets Retry in the sentence's face, size and line height, whatever the app's own rule for buttons says)"), so an app that gives its buttons their own font no longer makes the offline and error lines a pixel taller than the others.
- Fixed: the testing kit moves the mouse off the page before each test in the mouse projects, so [a test no longer inherits a hover](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/components/ouro/button/button.test.tsx "verify:testExists(registry/ouro/components/ouro/button/button.test.tsx::the pointer between tests > renders a button under the old pointer without hovering it, under a theme with a hover colour)") from the one before.
