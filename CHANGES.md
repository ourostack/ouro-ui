# Changes in this release

- Fix: `audit()` and `measureTextContrast()` leave no color easing outside shadow roots after they measure text; before, hiding and then showing the glyphs started each element's color transition, such as a link's underline, so the next measurement waited out that transition and took its screenshot while another was running ([test](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/testing/axe.test.ts "verify:testExists(registry/ouro/lib/ouro/testing/axe.test.ts::audit > leaves no transition running when it is done, its own text's or a link's elsewhere on the page)")).
- Fix: `audit()` now measures placeholder text, which axe leaves out, and fails a placeholder too faint against its field, such as one drawn at half the text color as Tailwind's base styles draw it ([test](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/testing/axe.test.ts "verify:testExists(registry/ouro/lib/ouro/testing/axe.test.ts::audit > fails a faint placeholder, as Tailwind's base styles draw one at half the text color, and passes one that meets 4.5:1)")).
- Fix: `audit()` and `measureTextContrast()` try a screenshot once more when it ran out of time on a box that shows and holds still; a stall in Vitest's Node process, which runs Playwright, could use up the limit while the page held still, and the text then failed as one that could not be screenshotted ([test](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/testing/axe.test.ts "verify:testExists(registry/ouro/lib/ouro/testing/axe.test.ts::audit > tries a screenshot once more when it ran out of time on a box that shows and holds still, as when Vitest's own process stalled)")).
- Add: the test kit's [`popups.ts`](registry/ouro/lib/ouro/testing/popups.ts "verify:fileLine(registry/ouro/lib/ouro/testing/popups.ts, /^const otherPopups: readonly OtherPopup\[\] = \[$/)") lists the popups Ouro UI's story check opens and how it opens them, tooltips, navigation panels and hover cards among them. It imports nothing, so an app's Playwright story check can open the same popups from the same list.
