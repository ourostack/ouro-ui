# Changes in this release

- Changed: MessageList draws shorter conversations whole again, as it did before it windowed them; windowing them comes back once code that scrolls through the list message by message keeps its messages drawn.
- Fixed: in Safari and WKWebView, squircle controls [no longer get a layer each](registry/ouro/theme/squircle-surface.test.tsx "verify:fileLine(registry/ouro/theme/squircle-surface.test.tsx, /gives no squircle control a layer of its own/)"), which slowed scrolling. The fill is clipped by [Bézier corners](registry/ouro/theme/squircle-surface.test.tsx "verify:fileLine(registry/ouro/theme/squircle-surface.test.tsx, /draws each corner as Bézier curves within 0.1% of the curve/)") and the ring is a rounded border, so typing beside them stays as quick as with the old five-point corners.
