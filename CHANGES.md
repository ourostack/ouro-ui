# Changes in this release

- Faster: in a MessageList, a message whose action bar sits beside its bubble is a size container [only while the list's bar is on it](registry/ouro/components/ouro/message/message-list.actions.test.tsx "verify:testExists(registry/ouro/components/ouro/message/message-list.actions.test.tsx::MessageList actions > makes a message with its bar beside it a size container only while the bar is on it, so a list opens without styling each one as it lays it out)"), so opening a conversation no longer styles each message's insides inside layout.
- Faster: MessageList [reads each cached height once a render at most, and none on a scroll](registry/ouro/components/ouro/message/message-list.windowing.test.tsx "verify:testExists(registry/ouro/components/ouro/message/message-list.windowing.test.tsx::MessageList windowing > reads each cached height once a render at most, and none on a scroll, so a long conversation's window costs little to find)"), and reads its children again only when the app hands in new ones, so opening and scrolling a long conversation cost less.
