# Changes in this release

- Fixed: [a controlled TextArea (and Composer, which wraps it) no longer rewrites the textarea's `defaultValue` DOM property, replacing its hidden text node, on every keystroke or unrelated re-render](registry/ouro/components/ouro/text-field/text-area.test.tsx "verify:testExists(registry/ouro/components/ouro/text-field/text-area.test.tsx::TextArea > syncs a controlled value through the DOM property, never rewriting defaultValue as the person types)"), so an app's own `MutationObserver` on the textarea sees only genuine content changes.
- Fixed: [when X-ray's backstop measures before its frame, it cancels that frame](registry/ouro/components/ouro/inspector/inspector.test.tsx "verify:testExists(registry/ouro/components/ouro/inspector/inspector.test.tsx::Inspector > cancels the frame its backstop beat, so that frame never measures a layer already unmounted)"), so a late frame no longer throws `own.querySelector` on a null layer after X-ray closes.
