# Changes in this release

- Fix: AttentionCard [hands focus to the next card](registry/ouro/components/ouro/attention-card/attention-card.test.tsx "verify:testExists(registry/ouro/components/ouro/attention-card/attention-card.test.tsx::AttentionCard > hands focus to the next card when its own action dismisses it)") (or the one before) when its own action removes it, as Alert does, where focus used to fall to the page.
- HoverCard: pressing its link no longer closes the card, which had closed on the press since the card started mounting on first hover.
- Fix: SwipeActions [hands focus to the next row's actions button](registry/ouro/components/ouro/swipe-actions/swipe-actions.test.tsx "verify:testExists(registry/ouro/components/ouro/swipe-actions/swipe-actions.test.tsx::SwipeActions > hands focus to %s actions button when an action chosen from the menu removes its row)") (or the row before's) when an action chosen from its menu removes the row, where focus used to fall to the page. Components that hand focus on when they leave now also [look past a list item that held only them](registry/ouro/lib/ouro/focus-handoff.test.tsx "verify:testExists(registry/ouro/lib/ouro/focus-handoff.test.tsx::handOffFocus > starts where %s that held only the element stood, when the item left with it)"), as ItemGroup's rows are.
