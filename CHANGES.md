# Changes in this release

- Changed: an Avatar of a picture another avatar on the page has loaded [draws it in its first render](registry/ouro/components/ouro/avatar/avatar.test.tsx "verify:testExists(registry/ouro/components/ouro/avatar/avatar.test.tsx::Avatar > draws a picture another avatar has loaded in its first render, with no second)"), with no second render to swap the initials for it, so a chat of people already seen opens faster.
- Changed: a Lightbox with thumbnails mounts its viewer's dialog only once a thumbnail is first hovered, focused or pressed, so a page or chat of pictures [mounts fewer components](registry/ouro/components/ouro/lightbox/lightbox.weight.test.tsx "verify:testExists(registry/ouro/components/ouro/lightbox/lightbox.weight.test.tsx::Lightbox's weight > draws $variant, unopened, in no more than $elements elements and $components components)"); it opens as before.
- Changed: in a MessageList, a message with actions no longer draws an empty slot for the list's action bar: the bar goes straight into the bubble's box, so such a message draws [one element fewer](registry/ouro/components/ouro/message/message.weight.test.tsx "verify:fileLine(registry/ouro/components/ouro/message/message.weight.test.tsx, /elements: 10,/)").
