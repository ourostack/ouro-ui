# Changes in this release

- Fixed: [MessageList keeps what a scroll write made while the wheel turns did not land drawn by the translate](registry/ouro/components/ouro/message/message-list.windowing.test.tsx "verify:testExists(registry/ouro/components/ouro/message/message-list.windowing.test.tsx::MessageList windowing > keeps what a write mid-wheel did not land drawn by the translate, until a later write lands it)"), so the reader's place does not jump against them in WebKit, where such a write lands in part.
- Fixed: Ouro check's first-run harness [gives each host's lookup in `unreachable` a limit](scripts/check/first-run-units.test.mts "verify:testExists(scripts/check/first-run-units.test.mts::first-run harness: the network > unreachable gives each host's lookup 3 s, holds without one that doesn't answer, and names it)"), so a fresh Mac whose first lookup of a host doesn't answer no longer holds a sign-in check until the resolver gives up. The network's ranges and its probe still carry the hold, and the evidence names a host given up on. Copy the check kit again to get it.
- New: `<Composer format="rich">` shows lists, quotes and code blocks as blocks, reads and writes them as Markdown, and Shift+Enter goes on or leaves a block while Enter still sends.
- New: `<Composer format="rich">` turns Markdown you type into formatting as you go: a dash, a number or `>` and a space start a list or quote, a fence starts a code block, and `**bold**` or `_italic_` format on the closing mark.
