# Changes in this release

- Changed: Avatar draws its initials or picture itself, without Base UI's Avatar, so an avatar of initials is [one component and no more than three elements](registry/ouro/components/ouro/avatar/avatar.weight.test.tsx "verify:fileLine(registry/ouro/components/ouro/avatar/avatar.weight.test.tsx, /variant: .initials., .*elements: [1-3], components: 1[ ,]/)"), and a chat, with one beside a message, opens faster.
- Changed: Avatar draws its initials from its surface's own `::before`, so [an avatar of initials is two elements](registry/ouro/components/ouro/avatar/avatar.weight.test.tsx "verify:fileLine(registry/ouro/components/ouro/avatar/avatar.weight.test.tsx, /variant: .initials., .*elements: 2, components: 1, classes: 23 \}/)"), and reads its colours from new `ouro-base` tokens, `--ouro-avatar-tint-*` and `--ouro-avatar-ink-*`, [mixed once on `:root` and `.dark`](registry/ouro/components/ouro/avatar/avatar.test.tsx "verify:testExists(registry/ouro/components/ouro/avatar/avatar.test.tsx::Avatar colors > takes each hue's mix from ouro-base in light and dark, and a .dark element's own mix for what is in it)"); until an app adds `ouro-base` again, an avatar's initials show untinted.
- New: a Command row has a weight budget of elements and class names, [enforced by a test](registry/ouro/components/ouro/command/command.weight.test.tsx "verify:testExists(registry/ouro/components/ouro/command/command.weight.test.tsx::Command row weight > draws $row in no more than $elements elements and $classes class names)").
- Fixed: a rich `Composer` the person isn't in no longer takes focus when the app changes its `value`, such as a draft an app writes while the person is in a dialog.
