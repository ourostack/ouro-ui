# Changes in this release

- Fixed: [MessageList keeps a wheel turning through one gap past the bound in an already-fast burst, instead of treating a page's own slow draw as the wheel having stopped](registry/ouro/components/ouro/message/message-list.test.tsx "verify:testExists(registry/ouro/components/ouro/message/message-list.test.tsx::MessageList > keeps a burst of short gaps turning through one gap past the bound, so a page it slowed draws late without paying mid-wheel (ourostack/ouro-ui#2830))"), so a carry is not paid against a wheel burst a slow machine only drew late.
- Fixed: [Message's leading-gutter time clears the row's focus ring](registry/ouro/components/ouro/message/message.test.tsx "verify:testExists(registry/ouro/components/ouro/message/message.test.tsx::Message actions > keeps the focus ring off a continued message's time in the leading gutter)") on a continued chat message, so a focused row's ring stops landing on the time's leading glyph.
- Fixed: [ConversationList row name order](registry/ouro/components/ouro/conversation-list/conversation-list.test.tsx "verify:testExists(registry/ouro/components/ouro/conversation-list/conversation-list.test.tsx::ConversationList > reads the title before a custom avatar's own words (a presence dot), whatever order the DOM draws them in)") a row's button now names the title and the rest of its content before a custom avatar's own words (a presence dot's label), so a screen reader hears "Sal Example 2:19 AM Quick question… Available" rather than the avatar's words first.
- Fixed: an external Link's icon stays glued to the text right before it at a narrow width, whatever that text is (a plain string or rich content such as bold text), instead of only when the text was a bare string.
- Fixed: ScrollArea's viewport takes a tab stop only when it scrolls and its content holds nothing focusable, re-checked as content changes, so a scrolling list of buttons keeps its tab stop at the lead button instead of gaining an extra stop on the viewport ahead of it ([test](registry/ouro/components/ouro/scroll-area/scroll-area.test.tsx "verify:testExists(registry/ouro/components/ouro/scroll-area/scroll-area.test.tsx::ScrollArea > gives no extra tab stop to a scrolling area whose content holds buttons, but keeps one for plain text)")).
- Fixed: Switch's on track draws Highlight under forced colours, matching its HighlightText knob, so a switch turned on still shows against a switch left off ([test](registry/ouro/components/ouro/switch/switch.test.tsx "verify:testExists(registry/ouro/components/ouro/switch/switch.test.tsx::Switch look and motion > fills the track under forced colours so an on switch stays visible, telling it apart from off in light and dark)")).
- Fixed: [ToggleGroup's `hideLabel` span](registry/ouro/components/ouro/toggle/toggle-group.test.tsx "verify:testExists(registry/ouro/components/ouro/toggle/toggle-group.test.tsx::ToggleGroup > names the group with hideLabel's own span, but keeps it out of reading order so the name is heard once)") is hidden from reading order with `aria-hidden` while it still names the group through `aria-labelledby`, so a screen reader hears the label once instead of twice.
