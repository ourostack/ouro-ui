# Changes in this release

- ouro-base: `ouro-skip-link` and `ouro-focus-target` (a skip link and the element it focuses), `ouro-focus-ring-within` (the focus ring on a label or box whose control has keyboard focus) and `ouro-reveal` with `ouro-reveal-host` (row actions or a card shown on hover or focus, shown from the start on a touch screen) give plain markup more of the components' states, and the Ouro source rule counts them as Ouro's. Add `ouro-base` again to get them; the plain stylesheet `site/public/css/ouro-base.css` has them too.
