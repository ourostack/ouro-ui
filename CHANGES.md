# Changes in this release

- Fixed: The shipped type tests check a call's props without passing children as a prop, so an app that lints for `react(no-children-prop)` [gets no hits from them](scripts/app-lint.test.mjs "verify:testExists(scripts/app-lint.test.mjs::no file an item installs passes children as a prop)"), and an update can't raise that count under its ratchet.
- Fixed: a `MenuSub` closed by the keyboard (the left arrow, Escape) [stays closed under a pointer that hasn't moved](registry/ouro/components/ouro/menu/menu.test.tsx "verify:fileLine(registry/ouro/components/ouro/menu/menu.test.tsx, /keeps a submenu the keyboard closed shut under a pointer resting where it was, and opens it once the pointer moves %s/)"), where the submenu had lain over its item and the browser's events for the still pointer opened it again; a pointer that moves, or [presses the item](registry/ouro/components/ouro/menu/menu.test.tsx "verify:testExists(registry/ouro/components/ouro/menu/menu.test.tsx::Menu items > opens a submenu the keyboard closed when its item is clicked where the pointer rests)"), opens it.
