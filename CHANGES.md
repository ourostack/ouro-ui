# Changes in this release

- Fix: packaged Button tests cover inherited and explicit action themes, including disabled opacity and palettes that stay the same across dark mode ([disabled opacity](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/components/ouro/button/button.test.tsx "verify:testExists(registry/ouro/components/ouro/button/button.test.tsx::button branch > disables natively with the theme's disabled opacity (%s))"), [dark action values](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/components/ouro/button/button.test.tsx "verify:testExists(registry/ouro/components/ouro/button/button.test.tsx::theme > switches to the dark action values under a .dark ancestor (%s))")).
- Fix: packaged Button tests distinguish a scoped primary fallback from an action override rather than assuming that action and selection palettes are the same ([scoped themes](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/components/ouro/button/button.test.tsx "verify:testExists(registry/ouro/components/ouro/button/button.test.tsx::theme > follows scoped primary fallback and action overrides without repainting soft buttons (%s))")).
- Fix: routing and guide navigation use a small page index instead of loading Markdown-only metadata into the initial page, while keeping page titles and descriptions ([generated index](https://github.com/ourostack/ouro-ui/blob/main/scripts/gen-docs.test.mjs "verify:testExists(scripts/gen-docs.test.mjs::the eager page index retains routing text without Markdown-only metadata)"), [page closures](https://github.com/ourostack/ouro-ui/blob/main/site/e2e/catalog.spec.ts "verify:testExists(site/e2e/catalog.spec.ts::each page loads only its own JavaScript closure, within its ceiling, and never Recharts first)")).
- Fix: a finished timer keeps its repeating alarm through a native Timer-to-tray or tray-to-Timer handoff without repeating its completion announcement ([handoff test](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/components/ouro/timer/timer-tray.test.tsx "verify:testExists(registry/ouro/components/ouro/timer/timer-tray.test.tsx::TimerTray > keeps a finished alert sounding through a %s handoff (passive reader=%s, completion write blocked=%s))")).
- New: `restoreTimer` imports a saved countdown without replacing an existing native timer, and reports failed persistence so an app can retain its original data ([existing state](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/use-timer.test.tsx "verify:testExists(registry/ouro/lib/ouro/use-timer.test.tsx::timer state transfer > preserves an existing stored timer instead of replacing it with an import)"), [blocked write](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/use-timer.test.tsx "verify:testExists(registry/ouro/lib/ouro/use-timer.test.tsx::timer state transfer > reports a failed import write while a mounted timer still works in memory)")).
- New: `resetTimer` cancels a timer by its id, updating mounted readers and clearing its saved state even when its screen is not mounted ([mounted readers](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/use-timer.test.tsx "verify:testExists(registry/ouro/lib/ouro/use-timer.test.tsx::timer state transfer > resets every mounted reader and its pending completion by timer id)"), [unmounted state](https://github.com/ourostack/ouro-ui/blob/main/registry/ouro/lib/ouro/use-timer.test.tsx "verify:testExists(registry/ouro/lib/ouro/use-timer.test.tsx::timer state transfer > resets a stored timer with no mounted reader)")).
