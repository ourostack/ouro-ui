# Changes in this release

- New: Command groups take [`alwaysShown: true`, every row of the group shown whatever the search is, under the group's label, with the empty state (`empty` or `emptyLabel`) above them, said politely once, when a search matches only such rows](registry/ouro/components/ouro/command/command.test.tsx "verify:testExists(registry/ouro/components/ouro/command/command.test.tsx::Command rows shown whatever the search > shows every row of a group marked alwaysShown whatever the search, under its label, and the empty state above them, said politely once, when only they match)"). The result count leaves them out, and a group's `forceMount`, cmdk's name, is a type error and a development message that name `alwaysShown`.
- Changed: Ouro Feel [reads a measure whose source saw nothing as unmeasured, never 0](scripts/feel.test.mjs "verify:testExists(scripts/feel.test.mjs::Ouro Feel's probe reads a measure as unmeasured, never 0, when its source sees nothing that a second source saw, in Chromium and WebKit)"): the probe checks each source against a second one (the list's scroll events, the frames that held a row or followed the reader's row) and names what it left out, with why, in the run's `unmeasured`. The report shows it, and a limit on a measure any run left unmeasured fails the case.
- Fixed: Ouro Feel [times each sample to the frame it measures, so after a long task a wheel's input to motion is no longer one frame late](scripts/feel.test.mjs "verify:testExists(scripts/feel.test.mjs::Ouro Feel's probe times a wheel event that waited behind a long task as the page's own frames do, in Chromium and WebKit)").
- Fixed: ListDetailPage [says how many entries match once you stop typing](test/patterns.test.tsx "verify:testExists(test/patterns.test.tsx::ListDetailPage > says how many match once the person stops typing, not while each key is still being said)"), so VoiceOver no longer drops the count while it echoes the keys you type.
