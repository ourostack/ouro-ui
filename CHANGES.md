# Changes in this release

- Fixed: Ouro check's `doubled-line` rule [skips a pair only when the element covering it has a fully opaque fill (alpha 1, no backdrop-filter, opacity 1 up its ancestor chain)](registry/ouro/check/design-check.ts "verify:testExists(test/check-design-in-page.test.ts::findDesignIssues: doubled-line > passes a pair of lines an opaque sheet covers, but still finds the same pair under a glass sheet)"), so a glass or translucent surface drawn over a pair of lines, such as a Sheet with backdrop-filter, still flags.
- Fixed: the same rule's hit test [no longer mistakes an element a scrollable ancestor has clipped away for one shown through a glass cover](registry/ouro/check/design-check.ts "verify:testExists(test/check-design-in-page.test.ts::findDesignIssues: doubled-line > passes a pair of hairline fills a scrollable ancestor clips away, even where an unrelated translucent box paints over their on-paper position)"), which wrongly flagged lines scrolled out of a `TimeGrid`'s view whenever some unrelated translucent element happened to sit at their on-paper position.
