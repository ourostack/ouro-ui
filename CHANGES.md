# Changes in this release

- Fix: ouro-base's avatar presence notch and squircleCorners()'s clip path now read their `shape()` back through a custom property instead of writing it straight into `clip-path`, fixing a stylesheet-parse regression in [the affected Chromium range](scripts/chromium-range.test.mjs "verify:testExists(scripts/chromium-range.test.mjs::CI's installed Chromium (from Playwright, pinned in package.json) is past the 149 to 157 shape()/var() regression range)").
- New: `<Avatar presence="unknown">` keeps its presence dot in the tree but draws neither the dot nor the notch, for a face whose presence has not loaded yet.
- New: Ouro check's [`off-centre-text` rule](scripts/check/check.test.mts "verify:testExists(scripts/check/check.test.mts::Ouro check > finds each rule on its fail page and nothing on any pass page, with a report, a contact sheet and close-ups) verify:fileLine(registry/ouro/check/new-rules.json, /\"rule\": \"off-centre-text\"/)") finds one line of words in a control whose cap height sits off the control's middle, such as a composer's placeholder pushed low by a bottom-aligned row; it is in `new-rules.json`, so an app's existing findings are recorded as known when it updates.
