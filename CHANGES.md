# Changes in this release

- Fixed: a Switch, Checkbox or Radio, in a CheckboxGroup or RadioGroup too, renders its control as a `<button>` with its role, which the label's `for` now names in place of the hidden input, so `getByLabel("…", { exact: true })` in Playwright and `getByLabelText` in Testing Library find [the one control](registry/ouro/components/ouro/switch/switch.test.tsx "verify:testExists(registry/ouro/components/ouro/switch/switch.test.tsx::Switch > is the one element its exact label finds, as Testing Library and Playwright look it up, and a click on that label flips it)") instead of two, and [a click on the label still toggles it](registry/ouro/components/ouro/checkbox/checkbox.test.tsx "verify:testExists(registry/ouro/components/ouro/checkbox/checkbox.test.tsx::Checkbox > is the one element its exact label finds, as Testing Library and Playwright look it up, and a click on that label toggles it)").
- Changed: hovering a Checkbox's or Radio's label now [darkens its border](registry/ouro/components/ouro/checkbox/checkbox.test.tsx "verify:testExists(registry/ouro/components/ouro/checkbox/checkbox.test.tsx::Checkbox > darkens the box's border while its label is hovered, as a browser's own checkbox does) verify:testExists(registry/ouro/components/ouro/radio-group/radio-group.test.tsx::RadioGroup > darkens a radio's border while its label is hovered, as a browser's own radio does)") as hovering the control does, because [a hovered label hovers the control it names](https://html.spec.whatwg.org/multipage/semantics-other.html#selector-hover "verify:urlOk(https://html.spec.whatwg.org/multipage/semantics-other.html#selector-hover)"), which is now the visible control.
- New: llms.txt names [the items for common needs](scripts/registry.test.mjs "verify:testExists(scripts/registry.test.mjs::llms.txt names the items for common needs before an agent's first fetch ends, and each is a registry item)") (dark mode, a form, a confirmation, a toast) near its top, so an agent whose fetch reads only the start of the file finds them.
