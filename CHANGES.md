# Changes in this release

- Fixed: Ouro check's `clipped-text` [leaves out text while it fades out to nothing](test/check-in-page.test.ts "verify:testExists(test/check-in-page.test.ts::findSizeIssues: clipped-text, fading out > leaves out text cut while it fades out to nothing, and still reports it when it fades in or holds)"), such as Porthole's previous line when the words change while the check runs.
- New: Command items take [`alwaysShown: true`, a row shown whatever the search is, such as `Jump to "…"`, with the empty state (`empty` or `emptyLabel`) above it, said politely once, when a search matches only such rows](registry/ouro/components/ouro/command/command.test.tsx "verify:testExists(registry/ouro/components/ouro/command/command.test.tsx::Command rows shown whatever the search > shows a row marked alwaysShown whatever the search, after the matches, and the empty state above it, said politely once, when only such rows match)"). The result count leaves them out.
- Fixed: Ouro check's off-scale rule keeps going on an app with a negative or hairline spacing such as `margin: -1px` or `padding: 3px 8px`, where it used to stop with "Cannot read properties of undefined".
