# Changes in this release

- Fixed: Ouro check measures a page's first content again on a second load before it reports it over budget, and [reports the lower of the two](registry/ouro/check/check.ts "verify:testExists(scripts/check/check.test.mts::Ouro check > drops a first content over budget when its second load is within budget, since one slow response is the runner)"), so one slow load on a busy runner no longer fails the gate.
- Fixed: Ouro check [counts a press that starts a navigation as leaving the page before its address changes](registry/ouro/check/check.ts "verify:testExists(scripts/check/check.test.mts::Ouro check > counts a press that starts a navigation as leaving the page before the address changes, and presses that control no more)"), opening the page again, so a navigation that commits later can no longer end the check with "Execution context was destroyed".
- New: `Hero` gains a [`split` layout that sets the media beside the words on a wide screen](registry/ouro/components/ouro/hero/hero.test.tsx "verify:testExists(registry/ouro/components/ouro/hero/hero.test.tsx::Hero > switches to the split layout, with copy and media side by side from 64rem)"), and stacks them below that. The `column` layout gains top room above its eyebrow and [lines up with a 75rem page](registry/ouro/components/ouro/hero/hero.test.tsx "verify:testExists(registry/ouro/components/ouro/hero/hero.test.tsx::Hero > applies each layout's classes to its own parts only)").
- New: Ouro check's `type-scale` rule honours an element's opt-out: text inside an element with `data-ouro-allow="type-scale"` (or `all`) and a non-empty `data-ouro-allow-why` is left out of the page's text size and font weight counts, and the rest of the page is still held to the scale. A `document.body` opt-out still skips the rule for the whole page.
