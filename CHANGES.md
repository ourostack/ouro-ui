# Changes in this release

- New: ConversationFind, the find bar for a conversation: a box with previous and next buttons, the match's place ("2 of 5") said once per change as a polite status, Enter, Shift+Enter, F3 and Cmd or Ctrl+G to step, and Escape to close with focus back where it came from, for a MessageList's `find`.
- Fixed: a MessageList unmounted in the task it opened in no longer throws when it tries to hold its place afterwards.
