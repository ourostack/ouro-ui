# Changes in this release

- Changed: ColorSchemeToggle is [the dark mode control](scripts/registry.test.mjs "verify:testExists(scripts/registry.test.mjs::an agent that searches llms.txt for dark mode finds the item that does it)") in its docs and llms.txt, its docs give the import of ColorSchemeProvider and colorSchemeScript, and ColorSchemeProvider's example shows a Vite app's wiring.
- Changed: Form's docs start with [an example checked in the browser with its own onSubmit](registry/ouro/components/ouro/form/form.test.tsx "verify:testExists(registry/ouro/components/ouro/form/form.test.tsx::Form > checks in the browser with its own onSubmit, as the first example does: the error lands on its field with focus, the same mistake shows again after an edit, and a fixed value saves)"), for an app with no router or server, before the router examples.
- Fixed: Ouro check's and Ouro AX's install messages, guides and llms.txt give the paths to run them from in an app with src/, and the line a Vite app adds to tsconfig.app.json so its type check passes with [Ouro check](scripts/check-vite-types.test.mjs "verify:testExists(scripts/check-vite-types.test.mjs::a Vite app type-checks with Ouro check installed once its folders are left out, as the docs say, and fails without that line)") or [the Ouro AX kit](scripts/check-vite-types.test.mjs "verify:testExists(scripts/check-vite-types.test.mjs::a Vite app type-checks with Ouro check, the Ouro AX kit and its tests installed once their folders are left out, still checking what it imports, and fails without that line)") installed.
- Changed: Ouro Current leaves `.github/workflows/` alone and says so, since an app changes a workflow only with the `workflows` permission, which Ouro Current does not ask for.
- New: the Installing guide starts with the steps that set up a new Vite or Next.js app, [the Vite ones the install test's own app](scripts/new-app-steps.test.mjs "verify:testExists(scripts/new-app-steps.test.mjs::the guide's new Vite app steps write the install test's Vite app, with @ for its ~)"), and the home page and the components index link to them.
