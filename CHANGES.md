# Changes in this release

- Changed: an action declared once now shows [one name, description and consent question on its surfaces](scripts/ouro-actions.test.mjs "verify:testExists(scripts/ouro-actions.test.mjs::every surface shows the declaration's own words for each action)"), and a consequential action may declare its question (`confirm`); the registry door's App Intents now describe each action in the person's words.
- New: the guide "Add Ouro AX to an app you already have" adds the Ouro AX kit to an app without Ouro HX, and a test runs its steps on a fixture app.
